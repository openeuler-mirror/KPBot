# sra_test 故障排查

| 症状 | 检查 |
| --- | --- |
| 无算法注册/目标 | 当前工厂、Makefile、适配器与实际 Faiss 类型 |
| 编译/API 不匹配 | 头文件版本、编译条件、库接口和 ABI |
| 动态加载失败/加载错库 | ldd、RPATH/RUNPATH、环境及进程映射 |
| 数据/索引打不开 | 工作目录、相对路径、权限、类型与 hash |
| 参数未生效 | CLI 默认覆盖、配置文件、宏条件和 SearchParameters |
| crash/异常结果 | 包装索引加载、维度、decoder、buffer 和资源生命周期 |
| 吞吐缺失或异常 | 退出状态、完整日志、计时公式、循环统计和绑核 |
| Recall 变化 | 数据/图实例、metric、参数、归一化、并发与结果语义 |
先保留失败命令和原始日志，缩小到实际原因后修复。不要靠替换算法名、降低工作量、改变精度或重建不同索引掩盖问题。
