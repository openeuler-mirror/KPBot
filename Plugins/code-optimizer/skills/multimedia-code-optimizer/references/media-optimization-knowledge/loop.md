# 环路滤波与恢复手段

| 内核 | 具体实现 |
|---|---|
| Deblocking | 先计算边界强度与阈值掩码；全无滤波直接跳过，独立样本用弱/强滤波向量核 |
| SAO band | B 位样本取 `band=x>>(B-5)`，查 32 项偏移表，输出 `clip(x+offset[band])` |
| SAO edge | 计算 `sign(x-a)+sign(x-b)`，用 -2…2 类别查映射与偏移；相邻像素复用比较符号 |
| ALF | 按类别加载系数；同系数对称抽头先相加再乘；非线性形式先分别裁剪邻居差值 |
| CDEF | 每块求一次方向，按方向加载固定邻域偏移；对邻居与中心的差做 constrain 后乘权累加 |
| 可分离 Wiener | 水平 FIR 写环形行缓存，垂直 FIR 读缓存；对称系数合并抽头 |
| Self-guided | 滑窗维护和、平方和，生成局部系数；多半径分支共享输入与可复用统计量；[差分位图压缩系数表](core.md#差分位图压缩查表) |

SAO 偏移表按块参数一次构建，未启用带填零。edge 分类对相等值使用 sign=0。

原地滤波保留尚未使用的原始边界行/列，避免后续分类读到新值。Deblocking 保持规定边缘顺序；跨 tile/slice 的读取按边界可用性分派。

CDEF 的差值限制：令 `a=abs(d)`，`constrain(d,T,S)=sign(d)·min(a,max(0,T-(a>>S)))`，S 按强度与 damping 生成；T=0 时该项为零。按原权重累加后执行规定舍入与输出范围裁剪。

SAO 编码端类别计数与残差和见[分类统计](statistics.md)，复用类别掩码和邻边比较结果。

## CDEF 投影能量判向

某方向把块分成若干投影线，第 j 条线的和、长度分别为 Sj、nj。相对各线均值的总平方误差为 `Σx²-Σ(Sj²/nj)`；只用于选择方向时，所有方向共用 `Σx²`，因此只需最大化 `Σ(Sj²/nj)`，无需生成方向均值或逐点残差。

8×8 块的线长不超过 8，可把评分统一乘 840，用整数权重 `840/nj` 替代除法。两端等长线先合并平方和，再乘一次权重。对含半斜率的方向，先用 ADDP 计算相邻像素对之和，多个方向共享这批和，再以反转和 EXT 错位累计形成各投影，减少重复分组求和，方向遍历和平局次序不变。
