- `HashProbe.cpp` 的示例条件是至少 64 行的单键内连接，活跃行的键有效且相同，构建侧唯一，并且没有额外连接过滤。阈值属于这一实现。100 条键为 101 的销售查的是同一张内存日期哈希表，优化后仍输出 100 笔独立销售。
