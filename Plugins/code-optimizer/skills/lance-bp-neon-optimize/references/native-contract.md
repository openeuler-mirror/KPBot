# BP 内核边界补充

## 逻辑长度与物理读写

历史 InlineBitpacking 单块路径对完整物理块解包，输出为 1024 个元素。短逻辑尾块仍提供完整目标空间，内核写满后发布长度，再按逻辑值数截断。不能将一个值的逻辑请求等同于只允许提供一个写入位置。

核对输入读取范围和输出写入范围。容量可以支持在边界内的原始指针写入，但不表示未写内容已初始化。沿用 MaybeUninit 或原始指针约定，不创建覆盖未初始化区的已初始化类型切片。

## 位宽与顺序

u32 的 0～32、u64 的 0～64 在解码器层面都需验证。NEON 适用集合可以更小，零宽、满宽和其他类型的原有回退不应被算成实际 SIMD 命中。

检查跨字拼接、FastLanes 排列、掩码和移位边界。C 中按字长移位存在未定义行为，Rust 与向量内建函数又有各自规则，不能盲目套用满宽掩码表达式。

新编码器与新解码器可能共享同一排列错误；需要已有写入器的数据或独立压缩字节参照。区分单块入口拒绝 1025 和多块入口正确处理 1025 的测试责任。

## 回退与部署

调用者若约定 false/None 表示“不适用且未写入”，候选必须在任何写入之前拒绝。部分写入后的失败需要明确状态与错误协议，不能假定普通回退会解决所有问题。

记录全局编译指令集和部署 CPU/系统要求。可选对象、分派及辅助函数分别检查，内部回退不证明整个全局特化程序可移植。编译、汇编、实际执行与目标性能分别验收。
