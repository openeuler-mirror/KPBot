# Kafka 实验记录模板

每次实验复制到新的 `results/<实验编号>/record.md` 并填写实际值。结果目录必须新建：目录已存在时停止，不复用、不覆盖旧证据。不适用项注明原因；仅保存脱敏配置和校验和，不复制认证凭据。以下文件位置相对本记录目录。

| 环境与负载 | 实际值或证据文件 |
|---|---|
| 编号、时间、目的、对比变量 | |
| broker/client 版本、commit（若适用）、发行包 URL/SHA-512 | |
| JDK、操作系统、架构 | |
| 集群模式、broker/controller 数量与拓扑、客户端位置 | |
| CPU quota/cpuset、内存限额、磁盘与网络 | |
| 脱敏配置及校验和、准确命令 | |
| 独立 topic、分区/副本数、各分区 ISR | |
| 消息条数、单条字节数、生成方式 | |
| acks、压缩、batch.size、linger.ms、生产者数量 | |
| 限速 records/s、预热轮数、测量轮数 | |
| smoke 结果、消费者位置与核对方式 | |
