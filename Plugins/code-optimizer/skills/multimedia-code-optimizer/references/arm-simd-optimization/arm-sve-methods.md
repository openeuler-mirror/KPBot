# SVE 优化手段

## 谓词与尾部

u16 元素用 `svcnth()` 步长与 `svwhilelt_b16(i,n)`；直接扩宽加载到 u32 时用 `svld1uh_u32`、b32 谓词与 `svcntw()`。按一次实际处理的元素数推进。

长循环可拆完整向量主段与单独尾段，主段复用全真谓词；短输入可直接使用谓词循环。输入输出元素宽度或数量变化时，分别构造对应访存谓词。

## 累计与条件筛选

acc 在循环外清零，用 `_m` 更新保留末轮未活跃 lane 的旧累计，结束后按全真谓词归约。`_z` 用于需清零的中间结果；`_x` 用于之后不会消费的非活跃结果。累计达到 lane 上界前扩宽或分段归约。

`svcntp` 计数满足条件的有效元素；`svsel(mask,v,0)` 后归约条件和。用 `svptest_any` 在整组无匹配时跳过昂贵路径。

## 间接访存与排列

`svld1_gather_u32index_f32` 的 index 以元素为单位，offset 形式以字节为单位；`svst1_scatter_u32index_f32` 对应分散写回。先计算有效地址谓词，再批量访存。重复目标的读改写需合并更新或分片，不能直接套 gather-add-scatter。

结构化加载/存储拆合交错字段；例如 `[a0,b0,c0,d0,…]` 用 LD2B 得到 `[a0,c0,…]` 与 `[b0,d0,…]`，用 LD4B 得到四条字段流。按实际字节序选排列，位字段打包采用各字段移位、掩码再 OR。

插入固定字段时，用 TBL 的越界索引生成零位，再 OR 常量。按实际输入字节数加载，不把输出的填充位置当成可读输入；跨向量的表用 TBL2。固定 128 位子块的排列见 [SVE2.1 分段重排](arm-sve2-methods.md#sve21-重排窄化与循环)。
