# A/B 协议、噪声判定与结论归档

没有同口径 A/B 的“优化”只是故事。本文件规定基线/候选的组织方式、噪声阈值、
保留/回滚判据与报告模板。

## 1. 术语

| 术语 | 含义 |
| --- | --- |
| 基线（A） | 未改动的二进制/配置/OS，代表当前生产或对照起点 |
| 候选（B） | 只改了一个变量的版本 |
| 轮次 | 一次完整的 warmup + run + 采集 |
| 噪声 | 非被测变量导致的波动 |
| 有效收益 | 超出噪声阈值且可复现的提升 |

## 2. 前置条件（缺一不可）

1. 功能门禁通过：mtr/冒烟/对账/复制/备份。
2. 两腿环境一致：硬件、OS、文件系统、挂载、绑核、NUMA、其他租户。
3. 两腿数据一致：同一快照/同一 prepare 参数，装载后行数与分布一致。
4. 两腿配置一致：除被测变量外，my.cnf 逐项一致（包括 PFS 开关）。
5. 两腿二进制可识别：记录 md5、commit、编译参数、依赖版本。
6. 采集口径一致：同一工具、同一并发/时长、同一 warmup、同一指标定义。

## 3. 运行顺序

推荐交错执行，抵消时间漂移：

```
A1 → B1 → A2 → B2 → A3 → B3
```

每轮之间：

- 重置数据到同一快照；
- 视需要清页缓存（`drop_caches`，独占机器时）；
- 确认无残留压测进程/连接；
- 记录本轮环境快照（温度、频率、其他负载）。

## 4. 噪声与判定

| 指标 | 建议阈值 | 说明 |
| --- | --- | --- |
| TPS/QPS | 轮间波动 ≤5% | >5% 先排查环境，不急着下结论 |
| p99 | 轮间波动 ≤10% | 长尾天然更抖，需更多轮次 |
| 错误率 | 读场景必须 0 | 非 0 先当故障处理 |
| CPU | 绝对值 + 相对变化 | 关注是否饱和、user/kernel 比例 |

p99 口径：必须来自正式压测 `--percentile=99` 的汇总或保留的延迟直方图。只有区间
`--report-interval` 的 p95 时，逐轮 p99 标“缺失（仅有区间 p95）”，不得用 p95 反推，
该轮也不参与 p99 的噪声判定与汇总对比。

判定规则：

- 收益 <5% 且轮间波动 >5% → 视为噪声，不保留。
- 收益明确但 p99 明显劣化 → 分场景判定，不能只看均值。
- 任一功能回归 → 直接否决。
- 多变量同时改 → 结论无效；拆成单变量重测。

## 5. 保留 / 回滚

保留条件：

- 目标场景收益超过噪声，且其他场景没有不可接受的回退。
- 正确性、复制、备份全部通过。
- 变更可解释（对应明确热点），可复现。

回滚条件：

- 无收益或负收益；
- 长尾/错误率劣化；
- 仅在某单一场景提升，却造成其他场景显著退化；
- 无法解释收益来源（可能是测量误差）。

回滚动作：

- 配置：恢复原文件并重启/热加载，确认参数生效。
- 二进制：恢复 `bin.bak.<ts>` 或旧安装目录，确认 md5。
- 源码：`git apply -R` 或恢复源码后重编，确认二进制 md5。
- 数据：仅在数据格式变更时使用升级前备份，禁止假设原地降级。

## 7. 归档

- 原始日志（sysbench/tpcc/pidstat/iostat/status 前后快照）与报告放在同一目录。
- 命名建议：`<date>-<scenario>-<A|B>-<round>-<binary-md5前8位>.log`。
- 结论写入团队台账，负结果同样记录，避免重复试验。

## 8. 常见失效模式（完整表）

| 现象 | 可能原因 | 处置 |
| --- | --- | --- |
| QPS 低但服务端 CPU 不高 | 客户端先瓶颈（连接池/序列化） | 加压测进程/核，减小结果集 |
| 写入 TPS 抖动、`Innodb_log_waits` 增长 | redo 太小/刷脏跟不上 | 增大 redo、提高 io_capacity、分盘 |
| 只读 QPS 上不去、CPU 低 | latch/内存分配/回表 | 转 hotspot-analysis 抓火焰图 |
| 错误率升高 | 锁冲突/超时/连接耗尽 | 看 `INNODB_TRX`、`PROCESSLIST`、错误日志 |
| P99 长尾 | checkpoint、purge、大查询 | 查刷脏、历史列表、慢日志 |
| 两轮差异大 | 数据未重置、缓存、其他租户 | 重置到同一快照、清缓存、独占机器 |
| 改完参数“提升”不可复现 | 多变量/噪声 | 回滚，单变量重测；>5% 波动不采信 |
| 新二进制结果不同 | 语义回归/数据格式不兼容 | 停性能测试，跑 mtr 与路径比对 |
- 至少保留：报告、两腿二进制 md5、配置 diff、逐轮原始数据。
