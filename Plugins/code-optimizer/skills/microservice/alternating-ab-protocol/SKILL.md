# alternating-ab-protocol — 单变量 A/B 交替基准测量协议

单变量优化效果验证的唯一可信路径：**同一台机器、同一时间窗口、交替执行**。
分组执行（先跑完 A 再跑 B）会让共享机器的慢漂移（温漂/邻居负载/页缓存）
伪装成差异——交替让每对相邻轮共享同一环境。

## 工作流程

```
准备 base/opt 两条命令（参数口径一致，仅二进制/库不同）
  → 交替执行 base → opt → base → opt ... 共 N 轮（默认 5）
  → 三级健康度判定（跨轮离散度 / 逐轮比值单调性 / 方向一致性）
  → 结论：N/N 同向（加快/变慢/无差异均可判）= 可下结论；混向 = 噪声区禁止下结论
```

## 可执行入口

```bash
# 5 轮交替（默认），每轮 1 次 warmup（不计时）
bash scripts/alternating_ab.sh -b "taskset -c 288-295 ./bench --repetitions=1" \
                                 -o "taskset -c 288-295 ./bench_opt --repetitions=1"
```

其余用法（3-4 轮趋势参考、7 轮收官加测、warmup 调整）与退出码契约见
[scripts/README.md](scripts/README.md)。

## 三级健康度判定

| 级别 | 检查什么 | 怎么判定 |
|---|---|---|
| 1. 跨轮离散度 | base 各轮测量值之间的变异系数 CV | CV ≤5% = 数据可用（硬门禁，超限 exit 1 禁止下结论）；安静微基准典型 1~3% |
| 2. 逐轮比值单调性 | opt[i]/base[i] 序列是否有单调漂移 | 持续单调上升/下降 → 环境漂移嫌疑，结果不可信 |
| 3. 方向一致性 | N 轮中 opt/base 是否全部同向 | N/N 同向（一致加快/一致变慢/无差异均可判）→ 可下结论；混向 → 噪声区 |

## 输出契约

- **stdout**：逐轮原始值（base/opt 各轮 ns）+ 逐轮比值序列 + 代表值
  （base 均值 / opt 均值 / 变化百分比）+ base 跨轮离散度 + 结论行
- **stderr**：异常详情（命令退出码/无可解析时间值时打印原始输出尾部）
- **退出码**：`0` 方向一致可下结论；`1` 噪声区或测量失败（命令异常退出/
  无可解析时间值/非正值/跨轮离散度超限）；`2` 参数错误（缺 -b/-o、
  -r 非正整数、-r <3、-w 非非负整数）；`3` 轮数 <5 的趋势参考（不可下结论）

## 成功、失败与 blocked

- 成功 = N/N 轮方向一致（或无差异）且离散度与漂移门禁通过 → 输出代表值与比值
- 失败（exit 1）= 噪声区（混向）、测量缺失（任一侧命令异常/无可解析值/非正值）
  或跨轮离散度超 5% 门禁
- blocked = 无（不依赖外部工具，纯 bash）

## 约束

- 只读操作：不修改被测环境
- fail-closed：任一侧命令异常退出或输出无可解析的正时间值（含负值与非法
  表示法）→ 立即中止，**绝不把缺失测量当作 0ns 计入方向统计**
- 单位自动换算：ns/us/ms/s → ns（支持科学计数法，防基准框架切换单位后误判）
- 交替而非分组：这是本协议的核心——共享机器的慢漂移会伪装成分组差异

## 和同类 skill 的分界

- 库专项优化（`protobuf-optimization` / `folly-future-optimization`）：
  那些消费本协议做库优化归因；本 skill 是**通用测量层**，适用任何单变量 A/B
- 火焰图/profiling 类（`flamegraph-libopt`）：回答"哪里热"；本 skill 回答
  "这个优化有没有效果"

## 错误处理

| 现象 | 原因与处理 |
|------|-----------|
| exit 1 + "命令异常退出" | base 或 opt 命令 returncode ≠ 0——检查命令本身 |
| exit 1 + "无有效的正时间值" | 命令输出无 ns/us/ms/s，或匹配到负值/零——检查输出格式 |
| exit 1 + "跨轮离散度超限" | base 各轮 CV >5%——数据不可用，排查环境噪声源或增加轮数 |
| exit 1 + "噪声区" 结论 | N 轮混向——增加轮数（-r 7）或排查环境噪声源 |
| exit 1 + "单调漂移" | 逐轮比值持续单调递增/递减——环境在变化（温漂/邻居），换时间窗重测 |
| exit 3 | 3-4 轮趋势参考——加测至 ≥5 轮再下结论 |
| exit 2 | 参数错误——检查 -b/-o/-r/-w 取值 |
