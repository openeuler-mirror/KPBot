# Velox Q67 多级聚合案例

来源：用户提供的 SQL67 skill 包随附案例摘要。本次导入未复跑真实引擎；以下历史数字不是当前环境的验收成绩，复用时应补齐提交、数据与原始日志。

Q67 有八个 ROLLUP 字段，产生九个层级。金额表达式是 `coalesce(ss_sales_price * ss_quantity, 0)`。同一笔 20 元销售可以进入商品小计、类别小计和总计。复用 20 元的计算，不改变各层分别累加的行为。

- `Expand` 与 `FilterProject` 之间可以复用同一批确定性金额表达式。
- `HashAggregation` 通过 `GroupingSet` 组织分组，再用 `HashTable` 定位。可复用经过确认的列向量前缀中间哈希，或在整批同组时共享定位。
- `DecimalSumAggregate.h` 的一个候选条件为 64 位输入且 128 位累加器高 64 位全零或全一；其余状态走原有溢出检查。迁移到不同累加器先读该实现的状态契约。

报告第 6 轮完整查询候选中位耗时 172.167 秒，相对起始实现累计加速 1.1342×。第 11 轮定点 SUM 的差分回放核对了 2,098,202 个状态。两组证据分别用于说明完整查询与局部正确性。
