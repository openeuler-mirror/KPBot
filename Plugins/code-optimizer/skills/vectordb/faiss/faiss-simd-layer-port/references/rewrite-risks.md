# SIMD 改写风险清单

## 通用改写

| 改写 | 风险 | 义务 |
| --- | --- | --- |
| 多累加器/展开 | 寄存器与代码体积；隐藏依赖延迟的收益被 spill 吃掉 | 尾部覆盖；FP 累加链顺序不变 |
| 查表 | gather 与寄存器查表的索引构造成本；lane 映射错误 | 表边界、VL 约束、lane 逐一验证 |
| 数据搬运 | 合并加载/替换 lane 构造引入越界或 alias | 对齐、合法读取长度 |
| 预取 | 距离/提示不当反而污染缓存 | 有效地址、带宽判据、对照 |
| 融合/缓存 | setup 与临时存储抵消主循环收益 | 一起测量、声明生命周期 |
| 归约 | 减少归约次数改变加权/精度/溢出 | 逐项等价证明 |

## 定宽层特有

| 风险 | 表现 | 防护 |
| --- | --- | --- |
| 谓词与类型宽度不一致 | 静默读错/算错 lane | 元素数与谓词模式成对定义并单测 |
| 单层常量跨翻译单元合并 | 不同 flags 的副本被链接器合并成错值 | 内部链接常量；实例化集中 |
| flags 泄漏到基线翻译单元 | 未保护代码出现越界指令 | 文件级属性作用域核对 + 反汇编抽查 |
| 类型双关违反别名规则 | 未定义行为 | 重构或声明宽松别名并记录 |
| 未实现特化 | 链接失败或静默走错层 | 实例化清单 + 分派掩码核对 |

每个候选先小范围验证指令形态与功能，再用完整冻结负载确认整体效果；微基准改善不能替代系统性能证据。混合标量与 SIMD 可能增加数据搬运；融合可能破坏已有向量化——这些是成本假设而非固定禁令。
