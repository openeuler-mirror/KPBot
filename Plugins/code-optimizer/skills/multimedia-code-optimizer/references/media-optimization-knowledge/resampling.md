# 插值、缩放与多相重采样

## 最近邻插值

固定映射分别预存横向源索引与纵向源行号；连续输出映射到同一源像素时按 run 广播，相同源行重复出现时复用已生成输出行。整数倍率放大按像素组复制，缩小按固定步长取样；坐标取整沿既定像素中心约定生成。

## 双线性插值

轴对齐缩放将四点加权拆成两行横向插值，再纵向合并；每输出列预存左右索引和横向权重，每输出行只更新纵向权重。两槽行缓存记录源行号，只计算新进入的横向结果；多通道共享索引与权重。横向结果保留所需精度，最终一次舍入的路径不新增中间舍入。

某轴相位为零时删除该轴第二个样本及乘加，两轴均为零时直接取样。权重和为 S 的整数形式用 `S*a+w*(b-a)` 替代两次乘法，差值和累计扩宽。一般仿射／透视映射使用[坐标与采样](geometry.md#坐标与采样)，不套用整行结果复用。

### 二倍上采样的四相位合并

四邻点排为 `[a b; c d]`，输出采用围绕四个角旋转的 `9:3:3:1` 权重。先算 `p=a+d、q=b+c、s=p+q`，再算 `u=(s+2q)>>3、v=(s+2p)>>3`；四输出依次为 `RHADD(a,u)、RHADD(b,v)、RHADD(c,v)、RHADD(d,u)`，其中 RHADD 为字节舍入半加。

首输出精确等于 `(9a+3b+3c+d+8)>>4`，其余三路同理。前级截断配合末级舍入半加，保留原来的单次舍入结果。两份宽加权和窄化后即可供四路 URHADD 使用，不再分别计算四个宽点积；两行输出用交织存储直接写回。

## 双三次插值

每轴四抽头，轴对齐缩放先算四行横向四点积，再纵向四点积；用四槽行缓存复用重叠源行。按横向源起点组织相邻输出，复用四点邻域；各相位预存四个权重，避免逐像素计算三次多项式。系数随相位变化时按 Horner 次序求值并跨通道共享。

固定点系数量化后将权重和修正到目标尺度，使常量输入保持不变；负抽头保留有符号宽中间值，最终再裁剪。核参数作为系数表的一部分保存，边界合并映射到同一源样本的权重。降采样采用抗混叠核时，按缩小比例扩展支撑，不能仍固定四抽头。

## Lanczos 插值

核 `h(t)=sinc(t)*sinc(t/a)` 在 `|t|<a` 内取值，sinc 使用 `sin(πt)/(πt)` 且 sinc(0)=1。固定比例按相位预存抽头、源起点及归一化权重；可分离的二维缩放用横向行环接纵向点积，避免为每个像素重复求三角函数。

缩小比例 s=输出尺寸/输入尺寸<1 时，抗混叠核使用 `s*h(s*t)`，支撑扩到 a/s，再按实际抽头归一化；每轴独立生成系数。整数相位中的 sinc 零点删除对应抽头，相位对称时复用反向系数表；负叶瓣使用有符号中间值，裁剪放在规定输出节点。

## 整数倍率专用核

固定尺寸预存每个输出的源起点、相位和系数，同相位共享表；坐标包含像素中心、色度位置及边界模式。

整数采样步长、固定相位用固定偏移与权重替代逐像素坐标及相位查表；每个输出按采样步长推进输入，点采样、单向线性、二维 box 分别选核。

二维 box 只在末尾归一化时，直接宽累计窗口样本后缩放，可省中间图；分两级舍入时保留两个节点。大窗口或相邻窗口重叠多时改用滚动和。对称抽头预加、反对称预减，half-band 删除恒零抽头，±1 系数化为加减。

## 面积缩放

输出行覆盖的多行输入先逐列累成一条宽和缓冲，再按横向区间归并并除面积。横向区间重叠多时转前缀和，用两端相减；不重叠时顺序归并。分数覆盖的首尾样本按覆盖权重累计。

整数边界 box 中，固定步长 d≥1 的 `floor(x+d)-floor(x)` 仅取 floor(d) 或 floor(d)+1；按纵向覆盖高度预存两种面积因子，小数进位选择，末端截短窗口另按实际面积计算。分数边界加权路径使用其有效权重和。

## 多相分解

L 倍插零、滤波后 M 倍抽取：

```text
y[m] = Σn x[n]*h[m*M-n*L]
q = floor(m*M/L); p = m*M mod L
y[m] = Σj x[q-j]*h[p+j*L]
```

按相位连续打包系数，仅计算有效 tap。固定比例预存 `L/gcd(L,M)` 长的相位周期及输入推进量，省去除模。已有 h 沿原 L/M 分解；重新设计滤波器时可先约分。跨块保存相位与历史样本，采样原点包含滤波延迟。

### 点积后四相位插值

浮点 FIR 的各抽头共用相位插值权重 wr 时，交换两层线性求和：`Σj xj*Σr(wr*hrj) = Σr wr*Σj(xj*hrj)`。沿用原相位系数与插值权重，不逐抽头插值系数，而是先计算四组相位各自的点积，最后插值四个结果。

系数按抽头交织四相位，每次广播一个输入，一条向量乘加更新四个相位累计器；全部抽头完成后才做一次加权合并。相对逐抽头四权重插值再乘输入的计算，N 抽头乘法由约 `5N` 降为 `4N+4`，并移走循环内水平合并；不减少相位表密度、抽头数或输入精度。

## 双全通重采样的乘积复用

原算子已经采用偶、奇两套全通支路时，保持各节系数、支路次序和历史状态。一阶节写成 `t=a*(x-s)、y=s+t、s'=x+t`，同一个 t 同时用于输出和状态更新；每节只计算一次乘积，不分别展开两条乘加。

升采样时同一输入依次产生两支路结果并交织输出；降采样时偶、奇输入分别进入原支路，再按原规则合并。保持定点乘积移位和最终舍入位置，避免物化高速率中间缓冲。这里优化已有全通结构，不用全通滤波器替换原 FIR。

## 双线性最小二乘逆缩放

原算子求解 `min ||A*x-b||²`，A 为已知双线性放大矩阵。A 的每行只关联两个相邻源像素，正规矩阵 `AᵀA` 因而是三对角。保持同一个 A、边界和采样偏移，预先完成三对角 LU 分解并保存对角倒数，无需构造稠密伪逆矩阵。

逐行计算局部加权和 `Aᵀb`，生成一个位置就接入前向消元，随后反向回代；求解只做线性扫描。横向实现可转置一组图像行，让多个独立方程占据 SIMD lane，同步执行前向和反向递推，最后转置回连续输出。优化的是原有逆问题的求解方式，不把普通缩放换成逆缩放。
