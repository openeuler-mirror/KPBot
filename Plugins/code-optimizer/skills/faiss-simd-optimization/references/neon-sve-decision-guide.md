# NEON 与 SVE 选型

| 条件 | 决策检查 |
| --- | --- |
| 短输入/小维度 | 比较 setup、predicate 和水平归约，保留低开销路径 |
| 连续算术 | 检查实际 VL、执行吞吐和独立累加链 |
| 查表/gather | 计入索引转换、寄存器查表或访存依赖 |
| 位运算/popcount | 检查位序、加权与归约次数 |
| 融合/展开 | 比较代码体积、live 寄存器、spill 和缓存行为 |

选择来自当前硬件/编译器/负载的对照，不由向量宽度或处理器系列决定。混合标量与 SIMD 可能增加数据搬运；融合可能破坏已有向量化；这些是成本假设而非固定禁令。
需要尺寸/布局 guard 时说明依据，覆盖非命中路径与尾部。更改浮点归约或 FMA 应遵守预声明数值契约。
记录目标符号、实际 ISA/VL、维度/批量、分派、编译与汇编证据、对照结果和适用范围。
