# FIR、滑窗与多输出计算

## 分解、累计与融合

`K[y,x]=v[y]h[x]` 拆两次一维 FIR，直接二维定义不新增中间舍入。对称抽头先加、反对称先减，预加多留一位；half-band 删除零抽头，±1 化加减。

每 lane 放一个输出，逐 tap 广播系数、连续载入输入，多条独立链省水平归约。N 个 K 抽头输出需 N+K−1 个输入；K≤N+1 时两相邻向量用 extract 构造窗口，下一轮只补载新向量，窄重排后扩宽。因果 FIR 可反存系数，输出批完成再覆盖历史输入。

偏置按[常数与偏置](core.md#常数与偏置)折叠；各相位预存系数和与补偿，无效系数置零。

预测仅用于 SAD/SSD 时，插值→原舍入裁剪→求差累计，省整块预测缓冲。

## Gaussian 滤波

轴对齐二维 Gaussian 用横纵一维核分解；每轴对称权重将镜像样本预加后乘系数，中心抽头单算。固定 σ 与截断半径时预存归一化系数，整数化后修正系数总和；纵向只保留支撑范围内的横向结果。二维末尾才舍入时，横向保留宽中间值。

大 σ 且允许近似时，用多次 box 逼近 Gaussian：宽度 w 的离散 box 方差为 `(w²-1)/12`，选择若干整数宽度使方差和接近 σ²；每次用滚动和，比较最终核形状与输出误差，不能只匹配方差。精确指定截断核时可比较直接 FIR 与 FFT 卷积。

## 行环、Box 与行带

纵向 K 行窗保留 K 槽横向结果，记录源行号；只算新进入行，重复边界复用指针，消费完再覆盖。工作集由 H*W*b 降为约 K*W*b。

Box 维护纵向列和，再横向 `S'=S-leave+enter`；批内增量前缀和加前批末值生成一组窗口。半径 r 的输出按 h 行分带，各线程维护私有行环、读上下 halo，只写本带；额外行比例约 2r/h，源只读或预存将被覆盖区域。

## 滑窗转矩阵

相邻滑窗点积通过移位系数、补零共享输入；窗口并集超出目标点积块长度时，剥离端点项，主体用矩阵乘加，最后补回。优先剥离 0、±1 系数，降低补偿成本。

`y[p]=Σ(k=0…K−1)h[k]x[p+k]` 剥首项后：

```text
A  = [x[p+1], …, x[p+K]]
B0 = [h[1], …, h[K−1], 0]
B1 = [0, h[1], …, h[K−1]]
y[p]   = dot(A,B0) + h[0]x[p]
y[p+1] = dot(A,B1) + h[0]x[p+1]
```

两组输入作矩阵行，B0/B1 作列；不足块长度补零，超长则分段累计。补项在原舍入前与主体合并，累计范围按[位宽与归约](core.md#位宽与归约)推导。比较时计入打包、补项和输出重排，系数布局跨调用复用可摊销成本。ARM 映射见[I8MM 矩阵打包](../arm-simd-optimization/arm-neon-methods.md#i8mm-矩阵打包)。
