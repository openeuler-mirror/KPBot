# 量化代价与系数扫描

## 标量量化

固定量化步长预存倒数乘数、移位及修正参数，用宽乘法取高位替代逐系数除法；精确整数商的修正见[常数与偏置](core.md#常数与偏置)。对称量化先取宽化绝对值，完成阈值判定与量化后恢复符号；死区阈值单独预存，不能用普通最近舍入替代。

逐位置量化参数沿系数布局打包，连续处理相同位宽的系数；在量化写回时同步生成非零掩码、符号与非零计数，省去再次扫描。缩放变换的归一化可折入量化表，见[蝶形与量化尺度](transforms.md#蝶形与量化尺度)。

## RDOQ 增量代价

`J(l)=D(l)+λRlevel(l,ctx)+λRsig(l≠0,ctx)`，缓存 D(0)、显著性 0 状态基值及 0→1 差值；组标志、最后非零位置另计。复用范围绑定输入、λ、量化尺度、扫描位置及概率上下文，感知项计入 D。

反量化 `u(l)=floor((l*s+r)/2^q)`：先算 `v=l*s+r`，相邻等级用 `v>>q、(v-s)>>q`。令 `e=c-u(l)、δ=u(l)-u(l-1)`，平方失真差 `D(l-1)-D(l)=2eδ+δ²`；带权时再乘权重。跨 0、1、Rice 商边界更新信令。

组内 C 为非零系数失真＋幅值率，U 为其置零失真，S 为组内实际发送的全部显著性率。J 已含保留标志 G1 时，`Jzero=J-C-S+U-G1+G0`，率项含 λ。首组和最后非零组扣除隐含信令；选定后更新系数、位图及受影响上下文代价。

## 零、符号与位置位图

只取零/符号时，用有符号饱和窄化保留零与正负类别，再按扫描序重排（[ARM 映射](../arm-simd-optimization/arm-neon-methods.md#零与符号重排)），减少重排所需字节；幅值另读原系数。将非零/负数比较掩码与组内位权 `2^i` 相与后归约，各组按位置移位拼成非零位图 N、符号位图 S；组宽不超过位权元素的位数，拼接结果使用足够宽的无符号类型。

N 非零时以 ctz 定位、`N&=N-1` 清位；末位为 `W-1-clz(N)`，W 是 clz 操作数的类型位宽，不是有效位图长度。例如 16 位有效位图零扩展后传入 clz32，仍用 `31-clz32(N)`。相邻位置差减一生成零 run，再按格式拆长 run。稀疏位图可逐置位遍历；只求数量用 popcount，仅判全零用 OR。

按 N 的置位顺序抽取 S 中对应符号，压紧到低 popcount(N) 位；ARM 映射见[位图压紧](../arm-simd-optimization/arm-sve2-methods.md#位图压紧)。已知总非零数则逐组减计数，到零停止。反向扫描同时翻转 N/S 的 B 个有效位，提取位 i 映回 `B-1-i`，组间逆序；幅值按原索引取。
