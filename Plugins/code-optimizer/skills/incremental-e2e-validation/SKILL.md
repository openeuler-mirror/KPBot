# 多项优化的端到端增量验证

## 输入

从请求、已有实验和工作区获取原版身份、优化点清单与启停方式、依赖与互斥关系、叠加顺序、业务入口和目标环境。数量由用户决定。性能和正确性框架均使用用户指定的框架、命令、参数及判据。缺少可执行入口时先完成矩阵与条件清单，再明确缺项。

## 执行步骤

1. 按 [实验协议](references/protocol.md) 记录冻结条件、优化项身份、测试入口和预算。确认每项的局部证据及可切换方式。优先采用用户给定的顺序，未提供时提出满足依赖的顺序并说明依据。
2. 根据用户清单生成矩阵。可用 `python3 scripts/plan.py experiment.json` 生成配置、比较对和逐行结果引用。输入和命令见 [工具契约](references/tools.md)。缺依赖或互斥配置会保留原因，后续仅执行合法配置。
3. 从同一原版构造各配置，核实补丁、构建、运行开关及实际命中。每个合法配置先通过用户的正确性测试，再执行完整业务性能测试。复用历史结果需核对同一条件与配置身份。
4. 按预声明顺序和重复计划采样。每对独立或相邻增量比较只改变一个优化点，累计对照改变已声明的优化集合。发现其他条件变化时标记不可比并恢复条件后补测。保留所有失败及有效样本和原始日志。
5. 按协议逐对计算收益，核对环境漂移和波动。在预算内复测不确定项。阶段局部加速与业务实测分别记录。
6. 按 [报告模板](references/report.md) 向用户交付 N 行明细和一行全部组合汇总。每个收益格附比较引用、原始值、样本数及结论。收尾恢复事先约定的配置，并记录当前状态。

## 结果要求

- 独立收益比较原版与仅启用当前项。
- 增量收益比较前序组合与新增当前项后的组合。
- 累计及全组合收益均直接对原版实测。
- 小幅正向或负向变化可能来自波动时，在对应格注明“可能存在波动，方向未定”并给依据。
- 性能回退且正确性通过的配置仍保留原定组合路径。改用筛选后的路线时建立新的路径标识。
- 正确性失败、未命中、条件不可比及未运行分别记录原因，收益留空。互斥项导致全开不可执行时，保留全组合行说明原因。

## 联动

目标环境可用相应技能时，按名称加载其资源。通用证据核对可用 `verify-optimization`，向量检索漂移可用 `vector-experiment-methodology`，短算子噪声诊断可用 `kernel-paired-benchmark`。联动沿用用户的测试框架和验收线，局部诊断结果单列。技能不可用时执行本包协议并注明诊断限制。

## 工具

工具使用 Python 3.9+ 标准库，生成矩阵及计算描述性配对收益，实际构建、测试和采集由用户项目的入口完成。命令退出成功表示工具计算完成；实验验收仍需核对证据。

## 按任务选择入口

| 当前任务 | 需要读取的材料 | 交付物 |
|---|---|---|
| 首次设计多项对比 | 实验协议、执行手册 | 条件清单、矩阵、预计成本 |
| 已有可运行候选，准备采集 | 执行手册、数据契约 | 配置状态、逐块记录、正确性证据 |
| 已有测量结果，要求汇总 | 数据契约、报告模板 | 数据缺口清单与结果表 |
| 小幅变化难以判断 | 波动分析 | 自对照或复测计划及更新结论 |
| 中途中断后继续 | 执行手册的续跑章节 | 剩余工作与恢复记录 |

## 开始执行前的产物

用项目现有实验目录保存条件清单、矩阵和配置清单。
命名遵循项目习惯，保证同一配置和比较的标识可追踪。
先估算配置切换、正确性验证、预热和正式测试的总成本。
用户已有测试预算时按该预算执行。
优化数量增加时保留全部用户选择的项，并明确预算下的缺测范围。

优化点可由多个紧密相关的代码改动组成。
其边界由用户的候选定义和实际切换能力决定。
对无法独立启停的改动，报告可测单元及其包含的机制。
采用不同叠加顺序时，每条路径各自保存矩阵。

## 汇总入口

可用 `python3 scripts/report.py results.json > report.md` 生成表格。
该工具核对输入声明的条件、配置、完成状态、正确性和波动依据。
它读取记录并输出 Markdown，实际日志与命中证据由执行 Agent 审阅。
字段细节见 [数据契约](references/data-contract.md)。
工具的“观察到改善/下降”属于描述性判断，业务验收需结合用户门槛。

## 完成检查

- 用户选择的全部优化点都在表中出现。
- 每个独立、增量和累计格有实测结果或明确原因。
- 全部组合行引用最终组合对原版的测量。
- 正确性和条件一致性核对覆盖每个实际配置。
- 波动说明直接出现在受影响的单元格。
- 原始运行、异常样本、复测与排除理由可追溯。
- 当前生效配置及恢复结果已记录。
