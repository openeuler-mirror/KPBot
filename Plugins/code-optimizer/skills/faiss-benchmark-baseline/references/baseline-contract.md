# Faiss 基线契约

## 身份

记录参考源码 commit、已有补丁/工作区内容、编译器、真实宏/flags、依赖、测试程序及实际加载库。baseline_id 对应这些证据，不预设某个版本或扩展后端。
A/B 共享同一参考状态，候选 diff 和候选开关是已声明的差异；库 SHA256 分别记录，不要求两侧相同。

## 冻结字段

- 数据与索引：数据/ground truth、metric 与预处理、保存索引身份、训练/构建或 load 策略。
- 算法：实际索引参数、SearchParameters 覆盖、包装器、top-k、精排和质量设置。
- 构建：公共编译器、目标 ISA/库变体、优化 flags、链接方式、OpenMP/BLAS 及无关宏。
- 运行：逻辑 CPU 列表与物理拓扑、NUMA、worker/依赖线程、查询批量、缓存和资源边界。
- 测量：实际计时/聚合公式、预热、次数、顺序、质量比较、漂移与异常处理。
算法专属字段见对应 benchmark-contract.json；工具字段以实际适配器映射为准，示例不覆盖当前实现。

## 建立与复核

CP2 先核对身份并声明协议，再保留全部基线质量/性能值；CP6 前复核相同条件。记录 manifest、原始日志和每侧产物身份。训练/add 与查询计时分别报告。
冻结字段变化意味着新实验。旧记录身份不完整时注明缺失，不补猜；共享环境显著漂移时不能将旧基线当作当前可比结果。
