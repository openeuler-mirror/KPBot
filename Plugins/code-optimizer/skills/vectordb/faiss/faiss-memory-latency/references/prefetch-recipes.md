# 预取场景处方

| 场景 | 预取点 | 参数 | 启用 guard | 反例 |
| --- | --- | --- | --- | --- |
| 按索引取行（by_idx 距离/内积） | 主循环第 i 次迭代预取 i+ahead 的行 | 行长 min(d×4, 上限)；行内按缓存行步进；ahead 实测定 | 行数 ≥ 阈值；i+ahead 在当前列表内；目标 id 非负 | d 极小（行长不足一条缓存行）；带宽已饱和 |
| 精排（候选重算距离） | 候选集确定后、距离循环前逐候选预取 | 每候选一行 | 候选数阈值 | 候选行刚被粗排扫过仍在缓存 |
| 图遍历（HNSW 等） | 读邻居表时预取下一跳的邻居表/向量 | ahead 1–2 跳；邻居表与向量分别预取 | 度数与层级 | 深搜顺序下预取项被逐出 |
| 倒排码字块扫描 | 处理当前 32/64 元素块时预取下一块 | 块大小即行长 | 列表长度阈值 | 顺序访问已被硬件预取覆盖，软件预取徒增指令 |

## 参数确定流程

1. 先测基线 miss 与带宽利用率，确认未饱和。
2. ahead 扫描（1、2、4、8 …），每档报告每元素周期数；曲线谷值即取值。
3. 行长按访问的尾部截断：只预取将要读的部分，不为对齐多取。
4. guard 阈值取"收益–规模"交叉点；低于阈值回退无预取路径。
