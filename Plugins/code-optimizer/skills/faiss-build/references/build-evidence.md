# 构建证据

每个基线/OFF/ON 产物分别记录：源码 commit 与工作区差异、补丁/源文件身份、编译器与路径、CMake 配置、实际宏/flags、目标、依赖、输出库及 SHA256。
保留配置和构建日志、compile_commands.json 及必要的链接/加载映射。声明的开关是请求，实际编译定义是构建证据，运行时命中是另一项证据。
比较编译命令时只归一化已说明的输出目录差异，不能忽略 ISA、优化级别、链接方式、公共宏或依赖变化。调试路径导致的完整 ELF 差异不等于代码语义差异，但每个产物仍需独立哈希。
编译、链接或宏检查失败时保留失败尝试；报告限制和下一步，不把失败构建标为完成。
