# 连接输出字符串物化与所有权优化

## 说明与范围

聚焦连接输出到字符串向量的物化边界：可内联字符串直接写目标槽位，需要独立拥有的长串复制到输出缓冲区。Shuffle 的序列化拷贝、读端重建和压缩分别处理；本 skill 可在没有 Shuffle 的连接输出上独立使用。

## 与总入口及其他技能的分工

本 skill 是 [sql-shuffle-string-codec 总入口](../sql-shuffle-string-codec/SKILL.md) 登记的连接输出物化实施单元，负责 RowContainer 到输出向量的内联/长串表示及拥有方。总入口只负责热点定位、选择实施单元和组合验收，不再维护另一套物化步骤。

输出进入序列化缓冲后的字节搬运由 [写端固定拷贝](../sql-shuffle-fixed-width-copy/SKILL.md) 负责；解压后创建视图由 [读端重建](../sql-shuffle-string-reconstruction/SKILL.md) 负责。三处可以分别涉及所有权，但证据必须绑定各自的输入、输出和销毁点，不能拿连接输出寿命证明 reader 缓冲寿命。

## 输入

| 输入 | 核对内容 |
| --- | --- |
| 计划与热点 | 连接节点、实际输出列、RowContainer 提取入口、物化调用次数及耗时 |
| 布局与编码 | 目标 StringView 布局和内联字节阈值，flat/字典映射、NULL 位图及跨块情况 |
| 所有权 | 输入行容器、字符串堆、输出向量及缓冲区拥有方、复用与销毁点 |
| 验证 | 长度分布、重复输出映射、输入释放/复用样本、峰值内存和配对查询基线 |

## 实施步骤

### 1. 锁定真实物化边界

从连接输出映射追到 RowContainer 的列提取及 StringView 构造。把行指针/字典映射消解到实际值，再统计内联与非内联字符串数量。先测物化成本，避免把 join 探测或 Shuffle 压缩耗时记到这里。

### 2. 按实际布局区分内联与长串

从目标版本头文件取得内联容量、槽位大小和字节序。只在布局一致且类型为字符串时搬运内联槽位；空值单独维护有效位，空串保留零长度。字符数不能替代字节数。

### 3. 为长串选择拥有方式

若输出已显式持有输入缓冲，可保留受支持的引用路径；否则在输出拥有的字符串缓冲分配空间，复制有效字节后再发布视图。只复制长串 StringView 指针不转移所有权。分块分配时保证每个已发布视图指向稳定地址。

### 4. 保留映射和生命周期

依原输出顺序逐个物化，重复 join 配对不可被去重。先完成分配/复制，再更新输出长度和引用；分配失败、容量不足或不支持的编码遵守原错误/回退路径。输入迭代器进入下一批后，输出仍须有效。

### 5. 验证释放与复用后的结果

对 NULL、空串、内联阈值前后、长串、字典重复和跨块输入比对行值。释放或覆盖输入缓冲、复用行容器，再读取输出。原生环境增加 ASan/UBSan 及真实输出向量的析构/消费测试。

### 6. 单项计量与配对复测

记录内联槽位次数、长串分配/复制字节、缓冲保留内存及回退原因。只切换物化改动，比较局部吞吐、峰值内存和完整查询；生命周期正确是性能验收的前提。

## 约束与回退

- 内联阈值由目标布局决定；本地模型中的 12 字节不是跨版本常量。
- 别名、NULL、字典映射或缓冲寿命没有证明时保留原提取路径。
- 保留每个输出配对的值、顺序及重数；复制不能发布尚未初始化的字节。

## 交付与验收

交付调用入口、布局与拥有方表、分配/复制策略、输入复用反例和完整结果对照。记录 `内联输出数 | 长串数 | 复制字节 | 保留内存 | 回退原因 | 物化耗时 | 查询秒数`。

实现与证据细节见 [实施参考](references/implementation.md)。

## 本地用例与验证边界

从 Skill 根目录运行 `python3 cases/materialization-contract/run.py`，按 `cases/materialization-contract/case.yaml` 校验结果。使用 `python3 -O cases/materialization-contract/run.py` 或 `PYTHONOPTIMIZE=1` 重跑，结果应一致。用例通过普通布尔检查决定 `success` 和非零失败退出码。

用例验证内联/独立复制模型、重复映射及输入覆盖后的值；未运行原生 RowContainer、StringView ABI 或内存检查器。 未完成的目标端证据标为 `awaiting_target_evidence`。触发与边界评估规格见 [evals/evals.json](evals/evals.json)，规格不等于已执行模型评测。
