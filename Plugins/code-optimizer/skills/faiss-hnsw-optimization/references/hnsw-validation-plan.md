# HNSW 验证计划

## 建立对照

明确优化目标为构建还是查询。查询对照冻结保存索引、storage、metric、efSearch、top-k、并发方式和环境；检查 A/B 加载同一索引哈希。构建对照另外声明种子、输入顺序、efConstruction、线程及图质量指标。

## 功能矩阵

- 实际索引/容器路径的 OFF/ON 与 fallback。
- 空输入、小图、不同容量/搜索范围、重复向量和距离平局。
- visited 首次使用、复用、清理/epoch 回绕及并发所有权。
- 候选满容量替换、比较方向、结果顺序和无效标签处理。
- 实现确有量化、节点重排或批量距离时，覆盖精度、ID 映射和保存/加载兼容性。

## 系统与性能

在目标平台运行完整查询集和相关并发测试；记录 ID、距离与 Recall。纯查询实现优化要求结果满足预声明不变量，Recall 不下降。测试通过后按 `vector-experiment-methodology` 交错测量，记录 A 漂移和分数据集结果。构图随机性不能用于解释未经排查的查询差异。

## 报告

使用 `vector-ut-st-validation` 的 Schema 与校验器。说明未执行的 sanitizer 或跨平台测试、替代证据及残余限制；完整验收由 CP7 独立角色完成。
