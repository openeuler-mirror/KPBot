# SAD、SATD、SSD 与 SSIM

## 归约与搜索

M 个 B 位样本：SAD≤`M*(2^B-1)`，SSD≤`M*(2^B-1)²`。ARM 字节差累计见[宽累计与点积](../arm-simd-optimization/arm-neon-methods.md#宽累计与点积)。多候选一次加载源块，各自独立累计。

仅判优劣时，部分失真大于 best 即停；`J=D+λR` 用 `Jbest-λR` 阈值，R 未知用下界。组和满足 `Σg|Sg-Rg|≤SAD`，参考组和由积分图/滚动和获得，使用实际插值、加权、裁剪后像素。平值沿原搜索顺序。

固定源块内缓存 D，键包含参考帧、平面、尺寸、坐标/相位、插值、权重与度量；双参考包含两路。率代价另算，依赖前候选的搜索保持顺序。

## Hadamard 末级消除

末级蝶形输出 `[a+b,a-b]` 只接等权绝对值和时，用 `|a+b|+|a-b|=2*max(|a|,|b|)` 消去该级。令 M 为 max 总和，输出 `(2*M+bias)>>shift`；独立或交错配对分别取绝对值与最大值，再宽化归约，省末级加减及仅为恢复自然顺序所做的重排；ARM 映射见[绝对值最大值归约](../arm-simd-optimization/arm-neon-methods.md#绝对值最大值归约)。

DC 单独加权的配对保留原计算，中间转置与各子块舍入保留。int16 最小负数先扩宽再 ABS。

## 预测模式的变换域联合评分

无中间舍入的 Hadamard 满足 `H(X-P)=H(X)-H(P)`。先对源块 X 做一次二维变换：垂直预测是顶行的逐行复制，其变换仅占一条频率轴；水平预测仅占另一条轴；DC 预测只占零频。顶行、左列分别做一维变换并乘块边长，即得到两条轴的预测系数。

三种模式共用不在两轴上的系数绝对值和，对轴上系数及 DC 分别减去预测贡献后更新代价。一次源块变换即可生成三路 SATD/SA8D 评分，不必构造三块残差，也省去另外两次完整二维变换。共同系数只归约一次，各模式最后再执行对应归一化。

## SSIM

等权窗口一次累计 `Sx=Σa、Sy=Σb、Q=Σ(a²+b²)、P=Σab`。N 点令 `V=N*Q-Sx²-Sy²、C=N*P-Sx*Sy`，总体方差评分为：

`((2*Sx*Sy+N²*C1)*(2*C+N²*C2))/((Sx²+Sy²+N²*C1)*(V+N²*C2))`。

样本方差只把第二因子稳定常数换为 `N*(N-1)*C2`。等权重叠窗口按尺寸与步长的公共网格累计子块统计，仅保留仍被后续窗口引用的统计行；网格过细时比较滚动和，任意矩形可用积分图，高斯权重用加权滤波。`Q≤2N*(2^B-1)²`，N*Q 与均值乘积先扩宽；每窗口完成后独立浮点评分，再归约分数。
