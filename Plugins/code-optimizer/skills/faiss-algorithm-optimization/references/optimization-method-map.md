# 热点到候选机制

| 热点证据 | 可评估机制 | 额外成本与风险 |
| --- | --- | --- |
| 算术/依赖链 | 循环组织、固定形状特化、SIMD | FP 顺序、寄存器、代码体积、guard |
| 解码/查表 | 地址计算、局部缓存、布局 | setup、缓存足迹、格式兼容 |
| 随机访存 | 预取、批量访问、局部性 | 带宽、无效地址、延迟摊销 |
| 结果维护 | 比较/容器、热冷分离 | tie、顺序、写维护、编译器布局 |
| 重复 setup | 按 query/list 复用 | 生命周期、并发状态、内存占用 |
| 调度/包装 | 批量、线程或分派组织 | 工作量、参数与测量口径变化 |

这些是候选机制，不是已验证的算法优化清单。用当前采样定位可移除成本；既有资料只在适用条件相符时支持假设。调参、精度或调度工作量改变要独立定义实验，不计入冻结配置的纯实现收益。
