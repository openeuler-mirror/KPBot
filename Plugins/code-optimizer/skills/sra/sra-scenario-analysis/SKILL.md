# 搜推业务场景分析

从已有材料归纳业务事实。报告要让技术读者能回答三个问题：什么条件触发这项业务，系统怎样处理候选，调用方最终得到什么。技术细节用于解释这些行为。资料不全时，按已有证据交付，并说明缺口对结论的影响。

## 从材料还原场景

1. **确定材料范围。** 找到业务说明或接口契约、实际入口及其调用链、配置生效点、测试输入与断言、运行记录。记下环境、版本和时间窗口。文档说明设计意图，源码说明该版本具备的行为，测试说明给定输入下的结果，运行记录说明该次请求实际发生的事件。材料冲突时并列记录版本、环境和差异。
2. **识别业务分支。** 从入口参数、路由、配置开关和用例中找出会改变参与组件、返回结果或业务状态的条件，选取有差异的路径。对每条路径串起触发条件、输入、处理规则和输出，跟踪候选在哪里被过滤、合并、改分或重排。流量占比要有统计依据；单个用例只证明对应分支。材料仅涉及精排时，边界就落在精排的输入和输出。
3. **把业务动作映射到系统。** 核实哪个组件负责每条规则，哪个接口传递候选、特征或分数。区分调用方向与数据流向。若涉及索引、模型或特征发布，沿已有版本或产物记录说明生产方、读入点和生效条件。区分声明的部署布局和运行时实例落点；判断某笔请求是否跨节点时，核对同一时间窗口内两端的实例与节点。
4. **核实结果与边界。** 沿同一请求区分服务端写出、调用方收包、业务展示和后台完成。对并行分支定位响应实际等待的结果；对超时、重试或异步写入，分别核对调用方看到的结果和下游已知状态。跨进程耗时需要可比较的时钟。未知项只列出影响及可供核对的材料，例如缺少生效配置或客户端收包事件。

## 组织报告

默认按[中文报告模板](assets/report-template.md)交付一份带 Mermaid 图的 Markdown 报告。模板规定完整报告的章节顺序和各图的职责；[已填样例](references/example-report.md)展示同一结构下的写法。仅请求单条链路或单一视图时，保留相关部分和证据。需要落盘且未指定文件名时，在本次交付目录使用 `搜推场景分析.md`，客户材料与通用 skill 分开保存。

- **先写业务，再写实现。** 开头用一段给出业务用途、主要规则和最重要的结果。分支差异用表，组件关系用图，现象的解释用正文。每个事实选一个主要位置；图下只解释从图中不易直接读出的结论。
- **先画用例视图。** 在系统边界外标出参与者，在边界内用动宾短语写其目标，例如“按时间查看结果”。参与者可以是人或外部系统。用例表接着写前置条件、主路径、会改变结果的异常路径和可观察的成功条件，给出对应测试编号。服务名、线程池和内部调用留给技术视图。
- **按用途绘图。** 架构图说明职责，部署图说明特定环境的进程与实例，时序图说明一次请求的先后与等待，上下游图和接口表说明依赖方向与数据契约。图题写明环境或路径。同一分支混用运行记录、测试和源码时，在相应步骤旁标明依据。只有服务端写出记录时，时序画到服务端写出。部署位置未知时画到已知边界；整张图没有材料支持时，在该小节用一句话说明缺口。
- **把判断落到证据。** 关键规则、部署关系和数字就近标证据编号，再在索引中给出版本及可复查的位置。业务目标、测试预期和实测结果分别标明。涉及指标时写清对象、单位、样本量、窗口和分母；必要时写起止事件、排除样本和对照条件。需要解释原因时，先给观测，再说明可支持的解释及尚待区分的因素。借助第三方资料解释术语时，客户系统的事实仍以本次材料为准。
- **交代如何验证。** 从已有用例、测试命令或配置、压测汇总和监控记录还原输入、负载、断言或计量方式、实际结果及适用范围。测试计划只有设计时标明“未见执行记录”。业务指标反映用户结果，系统指标反映吞吐、各级时延、CPU 和 DDR 资源消耗。按本次用例选指标；对明确要求但缺测的指标，指出缺哪个计数、端点或分母。具体选项和算法见[测试与指标口径](references/measurement-guide.md)。

## 中文写作与交付检查

- 用简短、完整的技术句，明确写出执行者、动作、条件和结果。例如，将“系统具备较好的降级能力”写成“特征读取超时后，排序服务按检索顺序返回候选”。首次出现且影响理解的缩写配中文释义；代码符号、配置键和事件名只在需要定位时保留原文，同一组件全文使用同一名称。
- 完整报告沿用模板的章节名；章内需要细分时，用业务问题或明确结论作小标题。删去通用行业背景、阅读材料的过程、空泛评价、重复小结和空表。表格用于比较，长解释放回正文，证据摘录放在索引。只保留影响读者判断的缺口。
- 选一个代表请求，从业务分支表走到时序图和接口表，核对输入、输出顺序、失败语义与结束事件。图中的实测事件只出现在对应分支。核对指标分母、图例、链接与证据编号；在可用的本地预览中检查 Mermaid。对客稿使用约定别名和可共享摘录，受限原件注明项目内核验位置，去除个人路径、凭据和原始用户标识。
