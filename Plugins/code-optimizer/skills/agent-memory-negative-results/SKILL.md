# 负结果台账与反模式

## 结构性无效

| 手段 | 结果 | 原因 |
|---|---|---|
| 服务端读路径补丁改善写入 | ±0.1 s | 写路径不经过这些解码例程 |
| 早期就测服务端补丁 | 收益 2~4% | Amdahl：客户端仍占 84~89% |
| 在解释型客户端里缩小锁粒度 | 收益在噪声带内 | 单线程事件循环下没有可并行的临界区 |

## 跨配置 / 跨架构反转

| 现象 | 数据 | 结论写法 |
|---|---|---|
| 服务端补丁在 AArch64 几乎无效，在 x86_64 高并发下近似减半 | 鲲鹏 p5 12.96 → 12.05（−7%）；x86_64 p5 15.59 → 8.12（−48%） | 不能写"服务端收益 3%"，要写"随并发度与架构变化" |
| 第 4 个补丁收益为负 | x86_64 3.15 → 3.22 s | 噪声带内（±0.07 s），不采纳也不否定，记账防重复 |

## 测量陷阱

| 陷阱 | 真相 |
|---|---|
| wall 当判据 | 固定开销稀释收益，只用 phase |
| 客户端优化后 L2/L3 miss 上升 | 载荷变小、空间局部性变差，属正常迁移 |
| 频率/睿频差异 | 同族不同频率档位，只比同机相对收益 |
| x86_64 上 L3 / L2I 计数 | 分级事件不可用，写"不可测"，别宣称数字 |
| 跨架构比较绝对值 | 只比趋势 |

## 台账格式

| 手段 | 结果 | 根因 | 启示 |
|---|---|---|---|
| 无收益即回滚 | 收益 < 3% 或跨架构符号相反时回滚 | 噪声带与架构差异 | 记账，避免下一轮重复试 |

## 与其他 skill 的关系

- 判定前先看这里，避免重复已证伪方向；
- 新负结果请按上表追加，并写清"在什么配置下无效"。
