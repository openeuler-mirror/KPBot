# 源码证据协议

## 记录

每项结论绑定 commit/源文件身份、相对路径与符号；引用行号时说明检出状态。工作区改动附 diff 或文件 hash。
使用[source]表示源码直接支持、[commit]表示 diff 支持、[inference]表示推断、[unverified]表示未确认。标记不能代替可定位的证据。

## 模板与分派

展开真实模板参数、条件宏、架构/运行时选择与 fallback。检查声明、实现、编译和链接是否齐全，不为启用某个 ISA 猜造宏。
运行时内核使用情况结合实际汇编和采样；源码存在或编译器支持某个指令集，不证明目标函数执行了该路径。

## 边界

只把当前检出可证实的结构、默认值和调用关系写为事实。跨版本或补丁后重新定位；找不到入口时报告缺失，不编造路径、行号或后端。
