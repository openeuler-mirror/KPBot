# 学习型内核手段

## 卷积

- 1×1、stride=1、无 padding：直接把像素与通道组织成矩阵乘。
- 一般卷积：展开后的输入可跨输出通道复用时，用 im2col 接 GEMM；展开量过大时分块展开或用 implicit GEMM，输出通道少时比较直接卷积，避免打包成本占主导。
- 小核、stride=1、dilation=1：Winograd 预变换固定权重，以输入/输出变换换取较少乘法；通道数和输出 tile 足以摊销变换、数值误差可接受时选用。
- 大核：复用权重频谱，分块 FFT 卷积；块尺寸兼顾补零、重叠计算与缓存。Depthwise 用逐通道专用空间核，减少打包与中间读写。

布局匹配后端向量轴与打包格式，相邻算子复用布局，固定权重跨帧复用打包结果。

### 像素指针展开卷积

NHWC 卷积把每个输出位置、每个核抽头对应的输入像素地址预存成表，每个表项指向连续 C 个通道；乘加内核沿指针加载通道，不构造完整 im2col 张量。越界抽头指向共享的零像素，坐标、stride、dilation 和边界选择移到建表阶段。

表按“输出微块 → 核抽头 → 微块内输出位置”排列，同一抽头的多个输出地址连续，权重块供这些输出共享。原展开区约需 `Ho*Wo*Kh*Kw*C*b` 字节，指针表约需 `Ho*Wo*Kh*Kw*p` 字节，b 为元素字节数、p 为指针字节数；通道数越大，免复制的空间收益越明显。

### 滑窗指针表压缩

对无横向 dilation 的滑窗，将同一输入列的 Kh 个指针连续存放。相邻输出窗口步长为 S、宽度为 Kw 时，表游标只前进 `Kh*min(S,Kw)` 项，重叠列直接复用；一行 Wo 个输出所需表项由 `Wo*Kh*Kw` 降为 `Kh*(Kw+(Wo-1)*min(S,Kw))`。

池化等内区窗口只随 y 整体平移的算子，纵向只存一条内区模板行，执行时给非零像素地址统一加行偏移；顶部和底部保留各自的边界行表。横向 padding 的零像素指针不加偏移。这样表的高度由整幅输出高度缩成“顶部边界行＋一条内区行＋底部边界行”，减少建表量和地址表工作集。

## 融合与量化

卷积后固定统计量 BN 按输出通道折叠：`a=γ/sqrt(var+ε)`、`W'=aW`、`b'=a(b-mean)+β`。bias、激活与残差按原顺序融合写回。

整数点积按 `Σqx·qw−zwΣqx−zxΣqw+K·zx·zw` 展开零点补偿，K 为点积长度。固定权重与零点时将 `−zxΣqw+K·zx·zw` 折入累加尺度下的 bias；对称权重 zw=0 还可省输入和修正。宽累计并加 bias 后乘 `sx·sw/sy` 重定标，加 zy 并裁剪；补边使用输入零点，权重尺度可按输出通道存储。

已有有符号四位权重可用[高位点积](../arm-simd-optimization/arm-neon-methods.md#四位权重高位点积)，在放大 16 倍的整数域累计，末尾统一转浮点并缩放。

## 分块 Attention

按 Q 行块遍历 K/V 块，在线更新 softmax 与 V 加权和，省去完整注意力矩阵的写回和读入；块尺寸兼顾 K/V 复用与累加器占用。逐行维护最大值 m、指数和 l、加权和 o；最大值更新到 m' 后，旧 l、o 乘 `exp(m-m')`，再加入以 m' 为基准的本块贡献，末尾输出 o/l。mask 在求最大值前应用，逐行跳过全屏蔽块；首个有效块直接初始化，最终全屏蔽行按接口定义处理。
