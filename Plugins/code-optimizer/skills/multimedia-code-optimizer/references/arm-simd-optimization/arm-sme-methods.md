# SME / SME2 优化手段

## SME：复用 ZA 中的输出块

| 计算模式 | 手段 | 实现要点 |
| --- | --- | --- |
| 同一输入向量参与多个输出乘加 | 把计算组织成外积，用 `svmopa_za32_f32_m` 累计到 ZA | 沿 K 读取 A 的列片段和 B 的行片段，一次更新整个输出 tile；输入按该访问方向 pack |
| 窄整数点积矩阵 | 用 `svmopa_za32_s8_m` / `svmopa_za32_u8_m` | 按指令分组打包 K 维，多个窄乘积累计到 s32/u32；尾部缺失项补零 |
| 多轮累计导致向量寄存器 spill | 输出累加器留在 ZA，普通向量寄存器用于输入与后处理 | 新输出块清零；累加到已有输出时先加载初值；在 K 循环外完成最终写回 |
| 块边缘不足完整 tile | 行、列分别使用谓词 | 输入尾部和输出写回使用对应方向谓词；不为补齐 tile 计算额外有效输出 |
| 后处理需要逐行向量 | `svread_hor_za32_f32_m` 等读取 ZA 行，向量内缩放/转换后存储 | 读回安排在累计结束后，避免每轮 ZA→向量→内存往返 |
| 转置必须经过中间缓冲 | 将 tile 按行写入 ZA、按列读取，或反向操作 | 利用水平/垂直 slice 访问改变布局；适合已在 SME 区域内的批量块 |

## SME2：多向量组累计

| 计算模式 | 手段 | 实现要点 |
| --- | --- | --- |
| 多组独立整数点积 | `svdot_za32_s8_vg1x2` / `vg1x4` | 一次操作成组输入向量，将结果留在 ZA；按加载能力、寄存器占用选择组宽 |
| 多组浮点逐元素乘加 | `svmla_za32_f32_vg1x2` / `vg1x4` | 将多个输出向量作为一组累计，避免每组都显式搬运累加器 |
| 多组输入复用一个系数向量 | 对应 `_single` 或 `_lane` 形式 | 避免为每个输入组复制系数；按共享整向量或共享组内系数选择形式 |
| 小块频繁进入/退出 SME | 合并多个块到一个 streaming 区域，复用 packed 输入和 ZA | 把分派、分配及普通辅助调用移到区域外；小任务无法摊销切换成本时保留 SVE2 路径 |

## 让编译器管理执行状态

- 整段内核使用 `__arm_streaming`；共享 ZA 的内部函数用 `__arm_inout("za")`，拥有独立 ZA 的函数用 `__arm_new("za")`。按实际状态所有权组合属性，让编译器处理调用边界。
- 在 streaming 区域按当前 SVL 组织块与谓词，不复用非 streaming SVE 下计算的 lane 数；布局索引和 pack 步长随执行区使用的向量长度确定。
- SME/SME2 内核按 CPU/OS 能力独立分派；f64、额外整数宽度及低精度浮点形式按相应子扩展选择，不能仅凭 Armv9.x 版本启用全部形式。
