# scripts/alternating_ab.sh

单变量 A/B 交替基准测量协议（纯 bash，无外部依赖，只读）。

## 用法

```bash
# 5 轮交替（默认），每轮 1 次 warmup
bash scripts/alternating_ab.sh -b "<base 命令>" -o "<opt 命令>"

# 7 轮收官协议（5 轮混向时的加测方案）
bash scripts/alternating_ab.sh -b "<base>" -o "<opt>" -r 7 -w 2

# 3 轮快速筛查（仅输出趋势参考，exit 3，不可下结论）
bash scripts/alternating_ab.sh -b "<base>" -o "<opt>" -r 3
```

## 输出契约

| 输出 | 含义 |
|------|------|
| 逐轮原始值 | base/opt 各轮的 ns 值 |
| 逐轮比值 | opt[i]/base[i] 序列——看单调性 |
| 代表值 | base 均值 / opt 均值 / 变化百分比（N 轮算术平均） |
| base 跨轮离散度 | base 各轮值的变异系数 CV（≤5% 硬门禁） |
| 结论行 | "方向一致"（N/N 同向：加快/变慢/无差异）或 "噪声区"（混向） |

## 退出码

| 码 | 语义 |
|----|------|
| 0 | 方向一致（或无差异），可下结论 |
| 1 | 噪声区（混向）、测量失败（命令异常/无可解析值/非正值）或跨轮离散度超 5% 门禁 |
| 2 | 参数错误（缺 -b/-o、-r 非正整数、-r <3、-w 非非负整数） |
| 3 | 轮数 <5 的趋势参考（3-4 轮同向也只作参考，不可下结论） |

## 实测形态

- ns/us/ms/s 自动换算到 ns，支持科学计数法（如 `1e-3 s`）；匹配到负值或零
  视为无效输出（fail-closed，绝不计入方向统计）
- 单位后须跟非字母数字字符（防 "seconds" 类误配）
- fail-closed：任一侧命令异常退出 → 打印输出尾部 + exit 1（不计零）
- 交替而非分组（核心协议约束）
- 方向判定对称：一致加快与一致变慢均为"可下结论"（后者是真实退化）；
  逐轮全等判为"无差异"

## 边界

- 双臂（base/opt）单变量——两侧命令参数口径必须一致（仅二进制/库不同）
- 多臂对照（如分配器三方）不在本协议范围
- 不做统计显著性检验——用方向一致性（N/N 同向）替代
