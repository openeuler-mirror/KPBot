# 共享机严格 A/B 协议

用于库级、跨进程、多尺寸的 A/B 验证。目标是在多人共享、存在静默干扰的机器上，得到可复现的配对结论，而不是单次最好看的数字。

## 1. 前置条件

```text
原版与候选：同一份源码版本、同一编译器与构建选项、同一库路径布局；
             两边只差目标改动（如型号白名单），不要一边用不同 -O 或依赖。
负载：       固定一个物理核，SMT 兄弟核空闲；驱动进程钉到远处另一个核。
环境：       governor/频率策略固定；记录内核、NUMA、负载与可用 CPU 掩码。
工具：       taskset/numactl、perf、/proc 统计；不需要 root 时优先用可读指标。
```

选核后不要中途换核：核忙就等待，然后原地重跑当前 invocation。来回换核会让变量随环境一起漂移，无法配对。目标机没有 SMT 时跳过兄弟核守卫，并在报告中记录该限制。

## 2. 基本流程

```text
1. 选一个物理核 C 及其 SMT 兄弟核 S，确认 S 在测试窗口内空闲；
   驱动脚本钉到另一个核 D，避免它抢占 C/S。
2. 按尺寸分档（至少覆盖小、中、大三类），每个尺寸先 warmup。
3. 每轮对每个尺寸跑原版 A 与候选 B，逐轮交替顺序（A-B、B-A 或随机区组）。
4. 每个 invocation 用新进程，避免同一进程内的缓存/状态跨轮残留。
5. 每档固定时长（如 3 秒）或固定迭代数；A/B 完全一致。
6. 记录每轮、每档、每方向的原始输出，不要只记平均值。
```

轮数建议 ≥5，优先 7；每多一轮，配对结论更稳。若目标机器是云上共享实例，记录“无法完全隔离”的限制。

## 3. 污染守卫

共享机上的静默污染主要来自 SMT 兄弟核、调度抢占和频率变化。以下守卫按可用性启用：

### 3.1 SMT 兄弟核忙时

```bash
# 读取兄弟核列表
cat /sys/devices/system/cpu/cpu$C/topology/thread_siblings_list

# 在 invocation 前后采样 /proc/stat 对应 CPU 行的 busy 增量
```

兄弟核 busy 增量超过阈值（例如 0.1 秒/次）即判为污染，等待后重跑。

### 3.2 非自愿上下文切换

每个 invocation 都是新进程，进程被回收后 `/proc/<pid>/status` 会消失，不能等命令结束再读。启动器必须在回收时记录累计计数，例如用 `os.wait4()` 的 `rusage.ru_nvcsw` / `ru_nivcsw`：

```python
import os, subprocess
proc = subprocess.Popen(cmd)
_, status, ru = os.wait4(proc.pid, 0)
proc.returncode = os.waitstatus_to_exitcode(status)
voluntary, involuntary = ru.ru_nvcsw, ru.ru_nivcsw
```

也可以使用 `/usr/bin/time -v` 输出的 Voluntary/Involuntary context switches。需要更细的时点就在进程存活时读 `/proc/<pid>/status`，但不要把它当作事后可补的数据。拿不到计数的轮次标 `ctx_switch=unverified`，不能默认 0，也不能据此判定污染或干净。

### 3.3 分尺寸偏差

维护每个系列（尺寸×方向×实现）的同期样本中位数。偏差超过 2%（大尺寸）或 3%（小尺寸）时，只作为排查信号，不能单独据此剔除样本：先看兄弟核忙时、非自愿上下文切换、频率/负载等独立证据。没有独立污染证据时保留该样本并标 `suspect`，在报告中说明；确需重跑时设定次数或时间上限，耗尽后把该系列标 `inconclusive`，不要一直筛到数字好看为止。

### 3.4 频率与 governor

`scaling_cur_freq` 只反映 governor 的目标值，`cpuinfo_cur_freq` 可能仅 root 可读。读不到硬件实际频率时，用“全部尺寸均匀变慢”作为降频/争抢的怀疑信号，而不是直接接受数字。

### 3.5 重跑策略

污染只影响当前 invocation，等待环境恢复后原地重跑；不要换核、不要删掉慢样本、不要只保留好看的轮次。保留污染记录与重跑次数；重跑设次数或时间上限，耗尽后保留数据并标 `inconclusive`。

## 4. 统计与判断

按「尺寸 × 方向 × 实现」汇总：

```text
n、均值、CV（样本标准差/均值）、min、max
Δ% = 同轮 B/A−1 的配对中位数
跨次运行（不同天或不同会话）的复现性
```

判断规则：

- 大尺寸收益达到测量前登记的唯一阈值（阈值须高于噪声下限，不能事后在区间内挑选），并且轮间与跨次运行方向一致，才可作为候选结论。
- 小尺寸允许落在噪声内或小幅负收益（固定开销、尾处理路径），但必须单独报告，不能被总平均掩盖。
- CV 超过 1% 要逐条解释来源；全部尺寸均匀变慢更像环境问题，不是补丁效果。
- 只报总平均、只报最好一轮、把单次差异当稳定收益，都不接受。

## 5. 通过条件与不可比条件

**通过条件**：正确性通过；probe 确认走了目标实现；大尺寸收益达到测量前登记的唯一阈值、高于噪声下限且可复现；小尺寸代价已说明；风险与合规可接受。

测量前同时记录：唯一阈值及其来源（业务目标、历史噪声下限等）、噪声估计方法、跨轮复现要求。噪声下限用同版本自对照或重复测量的波动估计；测量后按同一阈值判定，不因为结果调整阈值。

**不可比条件**：构建选项/编译器/库版本不同；机器、内核、频率策略或绑核不同；测量窗口内有其它负载；尺寸或方向不同；一次是单次对比、另一次是交替测量。出现任一情况，保留原始数字，标 `inconclusive`，不计算收益比。
