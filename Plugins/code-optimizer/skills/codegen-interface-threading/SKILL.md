# 新增算子语义参数的贯通改动

你是一位代码生成器接口贯通专家。先判断参数归属，再按七层贯通；旧入口必须语义等价，默认值不得改变既有产物。

## 触发条件

- 为生成器新增算子语义参数（如运行期缩放/累加系数、偏置、转置布局）。
- 把已有语义从编译期固定改为运行期可传入。
- 命令行能传但测量工具不认，或生成结果正确而基准数据异常。
- 新增入口与既有入口的语义需要保持一致。

## 输入

- 新参数的语义与取值域，以及它与既有字段的约束/互斥关系。
- 六个对外表面：配置文件与命令行、生成器入口、导出 C 符号、测量与校验工具、调优器、测试。
- 旧入口签名与它原本的语义（例如偏置构建中的预加载行为）。
- 序列化配置格式与历史内核标识。
- 布局/寻址信息：转置组合、基址推进方向、打包偏移。

## 执行步骤

1. **判断归属**：需要不同指令序列才进入内核配置；只改变调用方式则留在运行器或工具层。
2. **七层贯通**：配置 → 生成 → 导出符号 → 命令行 → 测量与校验工具 → 调优器 → 测试。
3. **兼容旧入口**：新入口承接全部语义；旧入口按原语义映射到新入口的一组固定取值，并写明映射。
4. **默认值不改产物**：默认值不写入序列化配置；未启用时生成结果逐字节一致。
5. **寻址类成对修改**：转置等语义让生成器与测量工具同时改，逐项核对基址、打包偏移与参考实现。
6. **保留诊断信息**：编译/生成失败时保留标准错误；失败记录不写入调优历史，但原因要可查。
7. **四组验证**：新旧入口等价、默认产物不变、非法组合被拒绝、工具与生成器一致。

## 规则

- 归属判错会放大搜索空间或让产物与声明不符；先判断再动手。
- 旧入口的映射关系一旦确定不要变动，外部调用方已按旧行为编写代码。
- 不支持的组合直接报错并指出冲突项，不要静默降级。
- 测量工具最容易漏；它不参与生成，但会独立解释布局与语义。

## 验证

- 新旧入口对同一组等价输入给出相同结果，覆盖默认值、非默认值与非平凡系数。
- 未启用新字段的生成结果与改动前摘要一致。
- 每个应报错的组合各有一条用例，错误信息指出具体冲突项。
- 用工具自带的一致性检查跑全部布局组合。

## 反模式

- 把调用约定塞进内核配置。
- 旧入口在偏置构建中改成纯运算，丢掉原有输出值。
- 序列化配置写入新字段默认值，破坏内核标识与历史可比性。
- 只改生成器不改测量工具，导致数值正确但基准异常或越界。

## 输出

- 参数归属结论与七层改动清单。
- 旧入口映射表。
- 默认产物摘要对照。
- 四组验证结果。
