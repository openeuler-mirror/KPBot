# SVE2 / SVE2.1 优化手段

## SVE2 整数数据流

| 计算模式 | 手段 | 实现要点 |
| --- | --- | --- |
| 窄输入、宽乘积 | `svmullb_s32` / `svmullt_s32`；累计用 `svmlalb_s32` / `svmlalt_s32` | b/t 分别取输入的偶/奇元素，不是向量的前/后半。若最终逐元素输出，保留两条独立流 |
| 成对求和后累计 | `svadalp_u16_m` 等成对扩宽累计 | 两个 u8 相加再加到一个 u16 lane；谓词按目的 lane 粒度构造，尾部无效源元素置零 |
| 绝对差累计 | `svabalb_u16` / `svabalt_u16` | 直接完成求差、绝对值、扩宽和累计；只需总和时可累计到同一宽向量，保留逐元素结果时分开 |
| 定点乘法后缩放 | `svqrdmulh_s16` / `svqrdmulh_s32` | 对 b 位有符号输入，计算乘积除以 2^(b−1) 后的舍入饱和结果；适合 Q 格式缩放 |
| 定点缩放后加减 | `svqrdmlah_*` / `svqrdmlsh_*` | 合并舍入倍乘高位与饱和加减；逐项舍入不等于宽累计后的统一舍入，按原计算节点选择 |
| 宽结果转窄整数 | `svrshrnb/t` 舍入；`svqrshrnb/t` 舍入饱和；signed→unsigned 用 `svqrshrunb/t` | b 写偶数位，t 保留偶数位并写奇数位。可能为负的输入不能套无符号 UQSHRN；不需舍入时选对应 QSHRN/QSHRUN 形式 |
| 加减后除以 2 | `svhadd` / `svhsub`；舍入加半用 `svrhadd` | 直接表达不丢高位的半和/半差；仅适用于原计算确实在此缩放的路径 |
| 连续多个向量使用同一系数 | 系数留在向量寄存器，选 `_lane` 乘加/定点乘法形式 | 按具体指令的组内 lane 范围复用；没有对应 lane 形式时广播一次后复用 |
| 表超过一个向量但能放入两个向量 | `svtbl2_u8`，用 `svcreate2_u8` 组合两张表 | 索引覆盖两向量拼接后的字节表；表随 VL 改变，越界结果为零 |

## 两条短组合

**偶奇扩宽后重新打包**：令 e/o 为偶/奇流的 s16 结果，`r=svqrshrunb_n_s16(e,s)`，再 `r=svqrshrunt_n_s16(r,o,s)`，输出为 `[e0,o0,e1,o1,…]` 的舍入饱和 u8。s 为指令允许的编译期移位常量；裁剪到小于类型上限的范围另做 min。

**尾部经过无谓词算术**：`svld1` 将无效源 lane 清零；乘加/查表等无谓词操作完成后，用输出粒度的谓词存储。含偏置、倒数或非零查表结果的路径，归约前另用 `svsel` 把无效结果置为单位元，不能只依赖加载时清零。

## SVE2.1 重排、窄化与循环

| 计算模式 | 手段 | 实现要点 |
| --- | --- | --- |
| 多个独立 128 位子块要滑窗/重排 | `svextq_*` 在对应分段对内提取，`svtblq_*` 按段查表 | 把独立块放入各段，重复局部索引；增加 VL 时增加独立块数，避免跨块串接 |
| 每个 128 位段复用段内一个系数 | `svdup_laneq_*`，对应 DUPQ | 每段各自选相同位置的元素广播；区别于 `svdupq_lane_*` 将一个完整 128 位段复制到全向量 |
| 两条 s32 流合并为 u16 | `svqrshrun_n_u16_s32_x2(svcreate2_s32(e,o),s)` | e/o 按偶/奇输出组织，融合舍入、无符号饱和窄化和交织；若需更窄范围，再做裁剪 |
| min/max 组合的整数裁剪 | `svclamp_*` | 合并 `min(max(x,lo),hi)`，匹配有符号性并保证 lo≤hi；末尾存储仍用有效输出谓词 |
| 一轮处理两个向量 | `svwhilelt_b32_u64_x2(i,n)` 与 `svget2_b(p,0/1)` | 两块复用各自谓词，第二块起点为 `i+svcntw()`；不足两块时可转单向量路径，避免构造越界指针 |

## 组合使用的独立扩展

| 已有能力 | 手段 | 实现要点 |
| --- | --- | --- |
| SVE 字节点积 | `svdot_u32` / `svdot_s32` | 每四个字节乘积累计到一个 32 位 lane；与全 1 向量点积可做分组求和，尾部无效字节清零 |
| SVE 16 位点积 | `svdot_s64` / `svdot_u64` | 每四个 16 位乘积累计到一个 64 位 lane；以输出分组排好输入与系数，重叠窗口可用 TBL 复用已加载数据 |
| SVE I8MM | `svusdot_s32` 做 u8×s8 点积；`svmmla` 做小矩阵乘加 | 混合符号点积可省输入减偏置及补偿；矩阵乘加按每个 128 位段的块布局打包 |
| SVE2 BitPerm | `svbext` / `svbdep` 压紧或散布每个 lane 内的位 | 用于位字段重排；这不是元素 compact，也不是内存 gather/scatter |
| SVE 元素筛选 | `svcompact_u32` / `svcompact_u64` + `svcntp` | 保序压紧活跃元素，以活跃数量推进输出指针；用新前缀谓词存储压紧结果 |

**完整累计上界**：对所有轮次的输入 xj、系数 cj 和初值 A，使用 `|A|+Σ|xj·cj|` 估算有符号累计范围，偏置也计入；四项点积的分组大小不限制整个累计链。可按已知正负范围进一步收紧位宽。

**相邻绝对差求和后宽累计**：SVE2 可用 `d=svabd_u8_z(pg8,x,y)`，再 `acc=svadalp_u16_m(pg16,acc,d)`。每个 u16 lane 一轮最多增加 510，从零最多累计 128 轮；奇数尾元素的另一输入位置清零。

## 位图压紧

SVE2 BitPerm 的 `BEXT(S,N)` 在每个 lane 内按 N 的置位顺序抽取 S，结果占低 popcount(N) 位；不同 lane 的结果需要另行拼接。用于[符号扫描](../media-optimization-knowledge/quantization.md#零符号与位置位图)时，N 与 S 保持相同扫描位序。

## 少类别直方图

SVE2 HISTSEG 在每个 128 位段内，为每个 key 计数该段 16 个字节标签中的匹配数。类别≤16 时各段重复 keys，同类别槽扩宽后跨段合并；每槽每批最多增加 16，u8 从零最多累计 15 批后扩宽并清零。无效尾部标签使用有效类别域外的值。算法中的类别和残差复用见[分类统计](../media-optimization-knowledge/statistics.md#小类别计数与残差)。
