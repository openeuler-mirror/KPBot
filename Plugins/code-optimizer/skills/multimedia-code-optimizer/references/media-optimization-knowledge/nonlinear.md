# 非线性滤波与增强手段

| 内核 | 具体实现 |
|---|---|
| 小窗口中值 | 固定 compare-exchange 网络，保留生成中位秩所需比较，不必完整排序 |
| 大窗口整数中值 | 窗口移动时减离开列、加进入列；扫描累计直方图找到目标秩，高位深用分层 bin |
| 平坦矩形腐蚀/膨胀 | 每 K 个值分块算前缀 p、后缀 s；长度 K 的窗口 [i,i+K-1] 取 min/max(s[i],p[i+K-1])，两轴分别执行 |
| 双边 | 预存空间权重、邻域偏移和差值权重表，累加 `ΣwIq` 与 `Σw` 后相除 |
| 直方图 | 每线程或分块私有 bin，结束后合并，减少共享更新 |
| Gamma / 点式曲线 | 有限整数输入域预生成 LUT；连续两表合成 `L[x]=L2[L1[x]]` |
| Unsharp mask | 复用低通结果 B，计算 `I+k(I-B)`，最后裁剪 |

## 中值滤波

小固定窗口采用 compare-exchange 选择网络，每 lane 对应独立输出，只保留通向中位秩输出的比较依赖。按邻域偏移加载整组像素，各比较在 lane 内完成；无需把每个窗口收集成连续数组再排序。窗口改变时重新选网络，不能直接截断完整排序网络的前几步。

大窗口、有限整数灰度域采用列直方图。K×K 窗口中，每列 Cx 保存当前 K 行的计数；向下移一行，每列只减去顶部像素、加上底部像素。窗口直方图 H 为连续 K 列 Cx 的和；向右移动时 `H'=H-Cleft+Cright`，省去逐一访问进入／离开列的 K 个像素。计数类型分别覆盖 K 和 K²；窗口位于边缘时，延拓样本按实际重复次数计数。

8 位灰度拆成高 4 位粗桶与低 4 位细桶，同时维护 16 项粗计数和 16×16 项细计数。中位秩 `q=floor(K²/2)+1`；先累计粗桶找到覆盖 q 的桶，再在该桶的 16 个细计数内寻找剩余秩。细桶可按需更新：每个粗桶记录细计数对应的水平位置，再次命中时补做期间的列增减；间隔超过窗口宽度时直接从当前 K 列重建该桶。

列直方图按竖向条带保存，条带两侧各含半径 r 的源列。灰度级数 B、计数字节数 c 时，列缓存约为 `(条带宽+2r)*B*c`，多通道再乘通道数。按缓存容量选择条带宽。小窗口优先选择网络；大窗口低位深优先直方图；高位深先估算 B 项列缓存，分层查找只减少查找量，不会自动消除底层计数存储。

## 腐蚀与膨胀

平坦矩形结构元素拆为水平和垂直一维 min/max。长度 K 的一维窗将序列按 K 个值分块，每块生成前缀 p 和后缀 s；窗口 `[i,i+K-1]` 的结果为 `min/max(s[i],p[i+K-1])`。一窗至多跨两个块；同块时窗口恰为完整块，重复合并不改变极值。纵向沿连续列并行，边界按结构元素锚点补齐。

流式一维路径可用单调队列：弹出队首过期索引，删除队尾被新值支配的元素，插入新值，队首即当前极值。每个样本最多入队出队一次，适合长窗口且不便保存整幅前后缀结果的路径；固定块扫描更便于 SIMD。

二值图将一行打包成位图，小结构元素用行位图的移位与 AND／OR 求腐蚀／膨胀；跨机器字传递移出位，尾字无效位按边界取值屏蔽。开／闭运算按先后顺序执行两次操作，以行缓存串接，第二阶段消费第一阶段结果。

## Guided filter

标量引导 I、输入 p：同一滑窗共享 `ΣI、Σp、ΣI²、ΣIp`，生成均值、方差、协方差及 `a=cov(I,p)/(var(I)+ε)`、`b=mean(p)-a·mean(I)`；a/b 共用下一轮 box 访问，输出 `mean(a)I+mean(b)`。同一引导图、窗口与 ε 用于多个输入时，缓存 mean(I) 和 `1/(var(I)+ε)`；彩色引导缓存对应协方差矩阵分解。

## CLAHE

各 tile 独立统计，裁剪后将超额 E 按 `E//B` 加到 B 个 bin，再按原间隔规则分配 `E%B` 个余数；前缀累加得到 CDF 并生成 LUT。输出像素查询相邻 tile 的 LUT 后按位置插值；预计算横向权重。clip limit、余数分配和插值舍入采用同一实现约定。
