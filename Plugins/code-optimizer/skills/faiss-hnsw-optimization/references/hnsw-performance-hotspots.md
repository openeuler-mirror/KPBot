# HNSW 热点检查项

本表用于组织采样，不预设热点排序或占比。以当前库、参数、数据和并发模式的测量为依据。

| 阶段 | 定位线索 | 归因问题 |
| --- | --- | --- |
| 图遍历 | greedy/search_from_candidates | 层级、扩展次数、邻接表局部性 |
| 距离 | DistanceComputer | storage 类型、维度、计算与访存 |
| visited | 分配/清理/标记 | 真实表示、表足迹、生命周期 |
| 候选容器 | push/pop_min/count_below | 读写频率、维护成本与容量 |
| 结果处理 | handler / 可选 ID 映射 | tie、结果顺序和标签转换 |

## 采样记录

记录事件、频率、样本/period 分母、丢失情况、self/inclusive 口径、查询计时范围、调用方和源码身份。架构与分支选择由真实采样符号和汇编确认；可选扩展不存在时不加入调用链。

## 候选判断

- 区分计算依赖、地址/解码、缓存、分支、寄存器及调度假设；全局 miss 率不能直接归因到局部函数。
- 调用很多不等于单次开销高，读点加速也可能增加写点维护成本。需要计数或对照支撑成本解释。
- 内联、展开、预取与更宽 SIMD 可能改变布局、setup 或寄存器压力，源码/指令数变化不等于真实收益。
- 仅将当前实验中的对照视为性能证据。资料中的结论用于提出或筛选假设，不能替代复测。
