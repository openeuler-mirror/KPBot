# 梯度、特征与区域

## 梯度与描述子

Sobel/Scharr 将平滑与差分分解为短 FIR，两方向共享邻域加载及行中间值；系数对称项先加、反对称项先减。只消费 L1 幅度时直接累计 `|gx|+|gy|`，只消费结构张量时直接累计 `gx²、gx·gy、gy²`，省完整梯度图；位宽按各自核系数与输入范围推导。

Harris/Shi–Tomasi 共享 Ix²、IxIy、Iy²；矩形窗积分图，高斯窗可分离滤波，计算 det(M)−k·trace(M)² 或最小特征值。FAST 亮/暗圆周位图检测连续段，先测试高淘汰率位置。

BRIEF 预存采样偏移，ORB 按方向旋转，像素对比较打包；二值匹配 XOR+popcount。WTA_K=3/4 对 `z=xor(a,b)` 归约 `(z|(z>>1))&0x5555…`，统计2位单元差异。

## Canny

四方向非极大值抑制令 `ax=abs(gx)、ay=abs(gy)`，比较 `ay` 与 `tan(π/8)*ax`、`tan(3π/8)*ax`，直接选择水平、垂直或对角邻点，免 atan2 和除法；对角方向由 gx、gy 是否同号决定。定点实现将两侧乘同一尺度后比较，乘积扩宽，方向边界与幅值平局沿原规则处理。

L2 幅值只用于比较时存 `gx²+gy²`，低高阈值同步平方，省去每像素开方；L1 路径保留 `abs(gx)+abs(gy)`。先用低阈值生成候选掩码，仅对候选计算方向和邻点比较。不能用 L1 替代 L2 后沿用同一阈值。

幅值保存前、中、后三行环形缓存；新一行梯度与幅值就绪后，对中间行做非极大值抑制并生成非边缘／弱边缘／强边缘状态。梯度按行消费，避免完整幅值图；状态图保留到连接阶段完成。

强边缘入栈或队列，检查八邻域弱边缘；弱边缘入队时立即改为强状态，避免重复入队。分块先做块内传播，再从跨块连接点继续传播，直到没有新增强边缘；固定一次 halo 交换不能覆盖任意长的弱边缘链。

## 区域与候选

连通域块内 union-find 压缩路径，按4/8连通合并边界后重标号；面积、包围盒、矩按根归并。

Hough 预存 sin/cos，按角度分片私有投票后合并；稀疏边缘先压点表。NMS 按分数与平局序排序，当前框批量计算后续 IoU 存抑制位集，顺序选未抑制框并 OR 位集；沿原端点和阈值比较规则。

## 距离与细化

平方距离两次一维变换 `d[x]=min_i(f[i]+(x-i)²)`。有限候选 i<j 的交点 `(f[j]+j²-f[i]-i²)/(2(j-i))`；新交点不大于栈顶时弹出，按区间求值。无候选输出无穷，需要欧氏距离时末尾开方。

二值细化的邻域判定可将 n 个邻点编码成 n 位索引，枚举原删除条件生成 `2^n` 项表，替代逐像素计数和逻辑组合；邻域小、查表成本低于判定时采用。Zhang–Suen 等多子迭代算法分别建表，同快照生成掩码后统一删除，再推进下一子迭代；tile 边界按子迭代同步。
