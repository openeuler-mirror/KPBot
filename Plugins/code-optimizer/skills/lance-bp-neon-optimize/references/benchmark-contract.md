# BP 测试口径补充

## 用例身份

在固定提交中扫描 benchmark 注册、辅助生成器和实际计时闭包，记录 target、group、完整运行名称、生成规则和计时范围。公开仓库读取不需要账号令牌；只有确实涉及受限资源时才使用已有授权凭据。

decode_inline_bitpacking_unchunk 的已知基础用例为 u32_bw12_1024 与 u64_bw23_1024，是否存在以当前固定版本为准。legacy_copy 和 typed_view 表示不同包装路径，compressed_bytes 是吞吐率口径，不是执行 NEON 的证明。

## 对照条件

两侧使用相同包装、压缩字节、物理块、逻辑尾长和计时边界。扩展全位宽属于自建扩展，保留官方基础用例并分别报告。生成器、编译器、特性、构建、亲和性与缓存策略随结果保存。

审计记录入口、实际 NEON 调用、值数和回退原因，正式计时关闭审计。记录各轮原始样本，不能删除退化和离群值来获得更好均值。

## 统计含义

Criterion 的一个样本可包含多次内核调用，样本数不能直接当作解码次数。时间加速比为原版除以候选；1.25 倍对应耗时减少 20%。跨位宽的几何均值不等于业务按工作量加权后的加速，需说明汇总权重。

核心正确性、命中和安全要求已在 SKILL.md 正文展开，本文件只补充测试口径。
