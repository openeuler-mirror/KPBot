# 余数/尾部拷贝

## 适用条件

- 拷贝长度不是 128B 的整数倍，尾部比例高。
- 小尺寸（<128B）或 tier 边界 + 小余数（如 4K+64B）占比较高。
- 想避免余数走 libc `memcpy` 的函数调用/分支开销。

不适用：
- 长度总是 128B 对齐；余数路径不执行。
- 小于 32B 的极端小拷贝：本方法用首尾重叠，仍需实测是否优于 libc。

## 方法

### 1. 32/64/96B 内联

在 384B 块宏内，对常见余数直接内联 `ldp/stp`，避免 `memcpy_rem` 调用。
必须按实际长度分派，不能对 `len <= 64` 固定写 64B：

```asm
add  x4, src, len
add  x5, dst, len
cmp  len, #32
b.ls rem_le32
cmp  len, #64
b.hi rem_65_127
ldp  q0, q1, [src]
ldp  q2, q3, [x4, #-32]
stp  q0, q1, [dst]
stp  q2, q3, [x5, #-32]
b    exit
rem_65_127:
ldp  q0, q1, [src]
ldp  q2, q3, [src, #32]
ldp  q4, q5, [x4, #-64]
ldp  q6, q7, [x4, #-32]
stp  q0, q1, [dst]
stp  q2, q3, [dst, #32]
stp  q4, q5, [x5, #-64]
stp  q6, q7, [x5, #-32]
b    exit
rem_le32:
/* 16/8/4/2/1B 递减，头尾各取一次 */
```

### 2. 1–127B 首尾重叠

`memcpy_rem` 不做逐字节循环，而是按长度分档：
- `1–32B`：16/8/4/2/1B 按位宽递减，头尾各取一次，允许重叠。
- `33–64B`：头 32B + 尾 32B，重叠覆盖中间。
- `65–127B`：头 64B + 尾 64B，重叠覆盖中间；不能用首尾各 32B，
  否则偏移 32 或中段会漏拷。
- 用 `%=` 生成唯一标签，避免宏展开冲突。

```asm
add x4, src, len
add x5, dst, len
cmp len, #32
b.ls rem_le32
cmp len, #64
b.hi rem_65_127
/* 33–64B: 头 32B + 尾 32B */
ldp q0, q1, [src]
ldp q2, q3, [x4, #-32]
stp q0, q1, [dst]
stp q2, q3, [x5, #-32]
b   exit
rem_65_127:
/* 65–127B: 头 64B + 尾 64B */
ldp q0, q1, [src]
ldp q2, q3, [src, #32]
ldp q4, q5, [x4, #-64]
ldp q6, q7, [x4, #-32]
stp q0, q1, [dst]
stp q2, q3, [dst, #32]
stp q4, q5, [x5, #-64]
stp q6, q7, [x5, #-32]
```

### 3. 余数继承 temporal 策略

save 的余数用 `stnp`，swap 的余数用 `stp`；不要只给主循环设置 hint，余数又回到
普通存储/加载。

## 验证

- 长度覆盖 0/1/2/15/16/31/32/33/63/64/65/96/127/128。
- 65/127 必须逐字节检查中段，不能只测首尾。
- 每个 tier 边界 ±1，尤其 4K+64B、8K+64B。
- 源/目标偏移 0/1/3/7/15/31/63。
- 前后哨兵 16B；逐字节比对。
- 如果替换成 glibc `memcpy`，必须用同一矩阵验证正确性和目标尺寸表现；否则保留内联。

## 反例

- 不要用逐字节循环处理 1–127B；分支/调用成本高。
- 不要只处理 32B 余数，忽略 33–127B 的重叠尾部。
- 不要把 save/swap 的余数 hint 混用。
- 不要因为“余数很小”就跳过逐字节验证；越界/重复写常在这里。

## 迁移到其他应用

- 先统计目标长度分布；整块占比高时余数优化收益有限，小消息多时才优先。
- 把 32/64/96B 内联和首尾重叠映射到目标拷贝函数；1–127B 边界按目标契约重测。
- 若目标编译器/libc 已对小尺寸更好，保留 libc 路径并说明适用边界。

## 证据

- 尾部按位宽递减/首尾重叠避免逐字节循环；参考实现保留内联余数。
- 本 skill 固化方法与门禁，不固化性能数字；目标应用需按自身负载复测。
