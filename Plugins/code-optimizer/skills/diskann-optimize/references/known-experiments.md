# I/O 实验设计

以下是待测机制和证伪方法，不是历史收益保证。

| 候选 | 必须观察 | 证伪信号 |
| --- | --- | --- |
| 增量完成派发 | 完成时间离散度、可重叠 CPU 工作、每查询时间线 | 大多数请求同时完成或调度开销抵消等待减少 |
| 注册 buffer / fixed read | 注册成本、生命周期、当前后端能力 | 无复用或成本主要不在注册/映射路径 |
| 逻辑重排 | ID 映射、访问局部性与物理 extent 的独立对照 | 收益只来自文件拷贝或设备状态 |

来源：当前源码的 reader 与 search 路径、实际构建和本次 tracing。外部历史记录需核对源码、环境和原始产物；不能假定当前版本提供某个 io_uring API 或下游 feature。
