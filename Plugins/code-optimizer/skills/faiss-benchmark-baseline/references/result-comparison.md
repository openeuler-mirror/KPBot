# 基线与候选结果比较

1. 先核对冻结字段、索引/数据身份、实际加载库与计时口径；不一致的结果不计算同条件实现收益。
2. 检查结果 ID/距离、Recall 和相关工作量的不变量，再解释性能。
3. 分工作负载报告全部有效样本、中位数、min/max 或 MAD、收益比值和交错对照中的基线漂移。
4. 按预声明目标判断矩阵中的收益/退化；数据集数量由任务确定。单负载改进不扩展为通用结论。
5. 变化小于或接近未解决噪声、各组方向矛盾或证据不足时，报告 INCONCLUSIVE 或明确复测要求。
使用 `vector-experiment-methodology` 的统计方法；最终结论同时引用正确性、构建、原始数据和适用范围。
