# Proxy 采集接入

## 准备与验证

1. 核对指定 Python proxy 的运行入口、文件来源和恢复方式。已接入的能力不重复改造；非 Python proxy 或无法确定接入点和恢复方式时，说明原因。
2. 在受限工作目录备份将修改的文件和启动配置，记录路径、权限、SHA-256、启动与恢复方式到 `run.json`，命令中的凭证不写入记录。
3. 按 [接入指南](../../references/proxy-integration.md) 在独立副本中接入 `scripts/capture_runtime.py`。复用已读的请求体，保持原鉴权、调度、重试和响应行为。P/D 钩子只用于实际有对应阶段的 proxy；未验证后端支持时维持 golden 关闭。
4. 在隔离端口和 mock 后端对比改造前、改造后关闭采集、改造后开启采集三组。核对普通与流式响应、异常、取消和断连，检查写盘故障不影响转发。清理本次临时进程；未执行的测试注明未测。

## 部署与恢复

- 验证通过后，交付修改副本、备份和测试结果，列出影响实例、在途请求风险、健康检查及失败恢复方式。只有用户明确授权后才替换与重启。部署前核对原文件哈希，在采集关闭状态下启动；健康检查失败时只按已授权的方式恢复。
- 用户要求恢复时另行确认授权，核对线上文件仍是本次部署版本，再恢复文件、权限和启动配置。只移除本次新增文件，重启后核对健康状态和实际运行入口，保留采集数据。状态写入 `run.json`。

本技能在隔离测试中验证采集，但不替用户开启线上采集。使用改造版继续采集时，交接运行入口、配置路径和健康检查结果。
