# 通用性能图表

## 输入

一个或多个 CSV/TSV/JSON/TXT、日志或目录，以及用户希望比较的指标和维度。输入可以来自多个实验、机器或版本，不要求用户预先合并。上游可以是 benchmark、性能采集、验证结果或用户提供的表格。

## 执行步骤

1. **先盘点并整理数据（reshape）**：列出相关文件、格式、表头、单位和实验身份。检查数据能否映射到绘图程序；不能时由 Agent 按当前数据结构做必要的解析、转置、宽长表转换或合并，再生成标准表。遵循 [数据整理](references/data-preparation.md)，保留原文件和行来源，不假设上游已完成。这里只提供流程，不要求固定 reshape 程序。
2. 确认指标、维度、独立运行编号与已有统计量，按 [数据契约](references/data-contract.md) 建立配置。同构文件可以直接使用 inputs 列表；异构 TXT/日志先整理为标准表。
3. 根据用户问题选择图型与分面。**有多次独立重复实验时必须呈现波动**：原始散点、箱线、明确标注的 min/max、SD 或其他可用范围，不能只展示均值。缺少原始样本/离散度时明确告知无法恢复波动，向用户索取相应数据，不虚构误差棒。参考 [统计规则](references/statistics-rules.md)。
4. 处理长标签：优先提炼不歧义的短名称；名称仍过长时采用 A/B/C/... 代号并附完整映射。程序对长类别横轴自动编码；检查图例和分面标题是否也需用户可理解的短名。不得丢弃完整名称和来源。
5. 保存配置，执行 `python scripts/visualize.py --spec <配置文件> --output-dir <输出目录>`。允许后续修改继续保存在同一目录，通过 output.run_name（如 v1/v2）或自动生成的前缀区分全部产物，不覆盖旧结果。
6. 核对文件存在、统计、样本数和来源。**仅当 Agent 有读图/多模态能力时才打开图片检查视觉布局**；不具备该能力时跳过图像读取，明确“图像视觉效果待用户检查”，请用户检查标签、图例、裁切及范围。不得声称已看图，也不因不能读图而阻塞产物交付。
7. 返回本次实际文件名对应的图表、索引、配置与数据路径。用户反馈后修改配置重绘，例如扩大 ylim；仍可使用同一输出目录，以不同名称保存。

## 输出

SVG/PNG（可选 PDF）、逐图数据 CSV、统计摘要 JSON、可复用绘图配置、输入与工具身份记录，以及 Markdown 图表索引。图表是主要交付物；依赖缺失或渲染失败时不能把仅有的数据文件称为完整交付。

## 依赖

Python 3.10+、Matplotlib 3.6+（包含 NumPy 依赖）。使用目标环境已有依赖；需要安装时遵循当前环境的安装权限。

## 约束

保留所有选中样本，过滤条件进入配置。不存在的组合不补零。不得从 min/max/median 还原分布，不把各轮 P99 的聚合称为总体请求 P99。图表用于呈现数据，不自动证明优化显著、可比或正确。

本版直接读取结构化数据和向量原始结果；其他格式由 Agent 在本流程前部完成整理，可按需调用已有解析技能。没有自动配对检验、置信区间、任意公式执行或收益归因。
