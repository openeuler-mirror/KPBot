# 连接快路径的分派与计数

## 同键批次

先处理空批次，再在当前活跃行集合中解码共同键。优先利用已知常量或字典信息；需要遍历识别时，将该成本计入候选，不以第一个键或相同哈希证明全批相等。复合键须证明所有分量，未支持时回退。

准入条件为已完成的同一构建表、支持的连接语义、非空且相等的活跃键、构建键唯一以及无未处理的逐探测行谓词。阈值是目标负载参数。条件不符时，在修改输出状态前进入原路径；已产生部分输出后不能再重跑整批。

一次探测得到的匹配引用只在当前表代次、分区与生命周期内复用。每条活跃探测行保留自己的字段。重复构建键不能只复用第一条匹配；本技能默认走原路径。spill、重建或切换分区使缓存失效。

## 短键判等

在只需要 equality 的调用点检查逻辑类型、排序/填充规则、NULL、有效长度和内联布局。字节等值条件不成立时仍用原比较器。长度不同即可不等；同长度比较有效内容。不得读取未初始化 padding，也不能将返回布尔值的函数接到需要负/零/正排序结果的接口。

## 计数口径

| 计数 | 放置位置/单位 |
| --- | --- |
| 输入批次、活跃行 | 批次入口；不包含未选中的物理行 |
| 同键检查行、通过批次 | 准入检查；包括检查成本 |
| 共享探测、普通探测 | 真正访问哈希表的位置；分别以调用计数 |
| 短键比较、通用比较 | 实际 equality 分派点；不同于哈希探测数 |
| 输出行 | 输出位置；可能大于探测数 |
| 回退原因 | 空值、混键、重复构建键、谓词、状态等互斥主原因 |

N 个活跃行、唯一构建键、同键且命中时，期望共享探测 1 次、输出 N 行；未命中仍共享探测 1 次但输出 0 行。用正常引擎调用和结果多重集核对，合成 Python 用例不证明真实路径命中。正式性能采集关闭额外计数，对照原版、仅批次、仅短键和联合模式。
