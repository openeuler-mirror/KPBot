# RaBitQ 源码调查示例

以下演示调查方法，不声明某个检出必然具有这些类或路径。
1. 在调用方搜索 RaBitQ 相关索引构造，确认是独立索引、IVF 还是 FastScan 变体。
2. 从对应 Index 头文件核对构造参数、训练/添加/查询接口和 SearchParameters。
3. 搜索实际 quantizer/packer，说明符号位、额外位和校正因子的生成与存储。
4. 追踪 DistanceComputer 的 set_query 与 distance/query_to_code 等实际接口，定位位运算、浮点校正和结果处理。
5. 展开架构分派并核对编译目标；运行时是否命中由实际汇编和采样确认。
6. 将每项源码事实绑定 commit/文件/符号/行号；成本与收益假设交给后续采样和实验。
缺少目标类或注册时，报告能力缺口及已有证据，不替换成相似算法继续声称完成调查。
