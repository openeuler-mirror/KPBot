# Faiss LUT 布局与生命周期

## 输入

LUT 构建流程（量化、归一化、偏置）、重排/打包步骤与成本、dim12/表足迹、单 LUT 与 3D LUT 语义、每列表查询数（nc）、列表长度分布、消费者（扫描器/累加核）的访问模式。

## 执行步骤

1. 分解 setup：表构建（每查询）、重排/打包（每列表，含 memset 填充）、分发到消费者；逐项计时得到 setup 占比。
2. 选择布局：连续打包缓冲（消费者顺序读、与 qbs 打包形态耦合）vs 行指针直寻址（零拷贝、消费者按行索引）；对比见 [布局对比](references/lut-layouts.md)。
3. 表足迹：M×ksub×元素宽 vs L1/L2 容量；超限时评估按子量化器组切片、分片驻留或压缩表示，并核对查表语义不变。
4. 接口两侧：布局变化要求生产者（搜索编排）与消费者（扫描器接口）同步扩展；两侧都要保留默认实现，未接线的路径走原布局。
5. 摊销：按 [摊销条件](references/amortization.md) 以两方案实测总成本（准备 + 扫描）的交叉点确定启用条件（nc、列表长度、M），不以"被消除的 setup 占比"作判据；不满足时回退打包路径。
6. 偏置与归一化：偏置表、normalizer 随布局同步搬移；两者错位是静默错误。

## 输出

布局方案、setup 分解数据、足迹与缓存预算、接口扩展点清单、摊销条件与回退、验证矩阵。

## 约束

- 单 LUT（每查询一份）与 3D LUT（每查询×probe 一份）的选择由索引语义决定，布局改造不改变该语义。
- 行指针在扫描期间必须保持只读有效；生命周期覆盖消费者执行全程。
- 布局不得改变查表含义、码字顺序与候选顺序。
- 打包消除的收益以冻结对照判定；memset/拷贝指令消失只证明实现形态。
