# 构建与实例化

## 逐翻译单元 flags

- 定宽层代码需要专属架构 flags（目标代次 + 定宽向量长度 + 别名策略），以文件级属性挂在目标内的指定源文件上，不污染全局或基线目标。
- 动态分发模式下，同一源文件可能同时进基线库和层级库：两侧 flags 归属要分别核对；含基线代码的翻译单元被加上高层 flags 时，自动向量化可能产生越界指令，必须以反汇编核对未受保护区域。
- 分派入口、回退与窄层实现固定在基线 ISA 翻译单元，只有定宽内核翻译单元携带定宽 flags：自动向量化按翻译单元 flags 给普通循环生成定宽指令（含 `ptrue`），混入回退路径在非兼容主机上即 SIGILL。
- 头文件里的层级判断（是否包含定宽特化头）依赖翻译单元的 flags，同一头文件在不同翻译单元展开出不同类型是预期行为，不是错误。

## 显式实例化

- 按层模板化的内核：把该层的显式实例化集中到一个按该层编译的翻译单元；其他翻译单元用 `extern template` 声明，防止在窄 flags 的单元里实例化出错误副本或重复符号。
- 跨层共享头（如按 level 模板化的通用内核）由各层翻译单元分别包含实例化；实例化清单变更时核对链接器没有静默丢弃副本。

## 证据

- 构建侧：compile database 中目标文件的真实 flags、宏展开、产物哈希。
- 链接侧：目标符号存在于正确翻译单元的产物中；调用点进入预期副本。
- 运行侧：进程实际加载的库路径与身份；门控命中的层与采样符号一致。

## 验证清单

- 基线库产物中不得出现高层指令（抽样反汇编热点函数）。
- 门控不满足时运行不崩溃且回退层生效。
- 单层与动态分发两种构建的同一测试集结果一致。
