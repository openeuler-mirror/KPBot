# 曲线缓存与颜色 LUT

## 一维曲线

有限整数点函数枚举输入域，逐级执行舍入裁剪，存最终值，连续点运算可合成一张表；b 位输入需 `2^b` 项，通道独立则分别建表。寄存器表按高位选片、低位索引；占用过多寄存器时改内存表，输入域过大或参数更新频繁时比较直接算术与分段近似。

连续复杂曲线采样一维表，缓存键含函数、参数、输入输出范围、标度、表长及有效元数据；亮度与色域分别缓存。不改变表内函数的外部仿射留在表外。恒等跳过，clip 用 min/max，仿射预存斜率截距；少段线性预存断点选段。曝光在线性光域，PQ 域变换在码值域。

选单调 u=g(x)，存 `F(u)=f(g⁻¹(u))`；按变换后曲率分配采样，输入已在 u 域则直接寻址。二阶可导区间线性插值误差≤`max|F''|*Δu²/8`；断点分段、端点入表，起点与跨度倒数预合并。

## 三维插值

三线性基址 `r*strideR+g*strideG+b*strideB` 计算一次，轴步长组合定位八顶点；沿三轴做 4、2、1 次 RGB lerp，通道共享权重，同单元像素共享顶点。最大边界选最后单元、小数为 1；next=prev 写法将相应步长置零。

四面体按轴 a/b/c 排序 `fa≥fb≥fc`，选 `000、ea、ea+eb、111`，权重为 `1-fa、fa-fb、fb-fc、fc`。比较/掩码选六种排列，权重供 RGB 共用；相等坐标固定平局序。四面体与三线性使用各自插值模式。

每通道一维 shaper 映射到立方体坐标，3D 表处理通道耦合；坐标域与后续映射不变时只更新 shaper。固定链可在网格点执行完整函数与舍入并烘焙成 3D 表，以采样近似换一次查询。
