# TurboQuant 参数与数据布局

## 参数与模型

从目标实现确认数据量化位数、centroid 数量、query 位宽、投影/旋转方式与校正模式。NBits、nb_bits、qb、int_qjl、qjl_type 等名称只在实际定义存在时使用；名称相似不保证语义相同。

## 布局检查

在 MSE/QJL 组合实现中，分别记录 MSE 索引/位平面、QJL 码和范数/校正因子的位置、步长、对齐与 code_size。额外 byte-index 缓存若存在，说明其存储开销、构建写入、查询读取和序列化兼容性。

## 中间状态

追踪 set_query 的投影、norm、误差系数、可选整数位平面和查表缓冲。确认每 query、每列表、每码字的计算边界及缓存复用条件。

## 数值与SIMD

表项能否放入一个向量寄存器取决于类型、表长和实际 VL；不要固定假设 256 位。整数/浮点 QJL、预筛阈值或精排倍率可能改变距离估计和候选集合，纯实现优化冻结这些配置。特化须覆盖维度、位宽、字节尾部、signed zero 及 NaN/Inf 等相关边界。
