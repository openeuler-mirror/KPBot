# 几何映射、抖动与绘制

## 坐标与采样

逆仿射行首先算源 u/v，沿 x 加矩阵第一列；透视分别递推两个分子与分母，再批量求倒数，w=0 或越界走边界路径。固定畸变映射预存索引、权重，尺寸/裁剪/相机参数变化时重建。坐标递推按原精度与采样中心生成。

整数起点＋相位索引查系数；双线性取四邻点。连续坐标普通加载，离散坐标 gather/标量收集；内部区与边界区分段，透明边界沿写入掩码执行。

## 旋转与转置

90° 顺时针 `dst[x][H-1-y]=src[y][x]`，缓存大 tile 内用寄存器小 tile 转置并反转，将跨行读写变为块内连续读写；寄存器转置从单元素开始逐级交织，每级将元素组宽翻倍。tile 按像素宽度、寄存器余量和缓存工作集选择。180° 直接反转行列，整数裁剪逐行复制；以完整像素为反转单位，子采样平面用自身尺寸与相位。

## 抖动

有序抖动以全局 `(x mod W,y mod H)` 选阈值，预存行相位向量或 `table[phase][value]` 融合量化，ROI/tile 延续相位。

Floyd–Steinberg 左到右误差分配右7/16、左下3/16、下5/16、右下1/16；用两行误差缓冲，逐行交换清零，保留扫描依赖和逐项舍入。蛇形扫描镜像邻域，量化器/调色板可制表。

## Span 绘制

先裁剪包围盒，活性边表逐 y 更新交点，按配对或 winding 生成连续 span；重复像素宽存储，非重复字节像素不用 byte memset。覆盖率与 blend 在 span 内融合；tile 内保持绘制顺序，端点、共享边和 clip/mask 参与跨度生成。
