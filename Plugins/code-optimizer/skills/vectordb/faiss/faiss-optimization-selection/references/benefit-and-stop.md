# 收益判定与止损

## 上界与摊销

- 上界 = 覆盖份额 × 可分摊比例；setup 类改动必须给出摊销条件（查询数、列表长度、批量大小）。
- setup 类改动按两条路径的端到端总成本（准备 + 扫描）比较，取交叉点作为启用门槛；不以"被消除的 setup 占比"或单一摊销比作否决依据——净增益在比值小于 1 时仍可能成立。

## 阈值拐点

- 分组核、预取、行式 LUT 等带启用阈值的机制，阈值必须来自实测"收益–规模"曲线的交叉点，不接受经验值。
- 曲线须覆盖阈值两侧至少各两个规模点；拐点随平台或负载漂移时，记录适用区间而非单点。

## 噪声带与最小可检测差异

- 看结果前预声明：重复次数、交错顺序（A1-B1-B2-A2 或更长）、中位数与离散度（min/max 或 MAD）、A 臂漂移阈值。
- 收益小于噪声带 → INCONCLUSIVE；各组方向矛盾或 A 臂漂移超阈值 → 复测或重新冻结，不得挑最好结果。
- harness 自带"取最优轮"口径时，额外保留每轮原始值并报告中位数；两臂必须同口径。

## 止损规则

- 实现后正确性不过 → 修复或回滚，不进入性能对照。
- 对照未超噪声带（含方向不定）→ INCONCLUSIVE：停止追加投入，保留证据或明确复测要求，与 `faiss-benchmark-baseline` 的对照结论口径一致。
- 明确负收益且超噪声带 → REJECT：回滚并保留证据与失败原因分析。
- 只在特定规模/形状有效 → ACCEPT_WITH_NOTES，记录 guard 与适用区间。
- 达到候选或测量预算仍无结论 → INCONCLUSIVE，停止追加投入。

## 记录格式

每个候选记录：机制假设、上界估算、guard/开关/回退、正确性矩阵、对照原始数据、结论与适用范围。结论写入 run_dir，不回写为技能的固定推荐或禁令。
