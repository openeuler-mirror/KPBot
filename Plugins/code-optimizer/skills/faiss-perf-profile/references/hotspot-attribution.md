# 热点归因

先确认真实计时区间和实际执行符号。将 self 与 inclusive 开销分开，展开调用方、模板、内联和包装器；百分比分母记录为样本数或加权 period。
高采样权重可能包含停顿和 skid，不能直接解释成该指令的可移除执行时间。全局 IPC/cache/branch miss 用于提出假设，局部瓶颈还需对应符号、访问或对照证据。
区分距离计算、解码/表读取、heap/容器、调度和测试程序结果统计。函数调用多、拒绝比例高或分支偏向都不足以单独证明应内联、branchless 或更换容器。
归因报告应说明事件/权限、栈质量、丢失样本、未知符号、覆盖负载及未确认项，再交给候选规划。
