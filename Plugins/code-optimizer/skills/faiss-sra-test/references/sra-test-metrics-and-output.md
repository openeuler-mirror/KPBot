# sra_test 指标与输出

## QPS与延迟

查看真正的计时起止、每 worker 查询数量、线程之间是分片还是重复查询，以及循环聚合方式。按 wall time 计算的总吞吐与平均 thread time 换算的吞吐是不同口径；保存原始字段名、公式和数值，不能仅因都称 QPS 就混合比较。

## Recall

确认 ground truth、top-k/Recall@k、metric、归一化、ID 对应和命中统计公式。召回数值相同不能代替逐结果 ID/距离一致性检查。

## 解析

对当前实际输出确定匹配行和单位，覆盖多轮、缺行、失败进程及不完整日志。保留 raw log，给出明确失败或缺失状态，不将缺失值当作 0 或成功。

## 比较

基线与候选使用相同工作量、计时口径和聚合规则。训练、加载、预热、诊断采样与正式查询测量分别标记。
