## 关键结论

- **ModelRunner V2 首个版本是 v0.13.0rc1**（2025-12-27），代码引入 commit
  `b69b04d3a91c`（2025-12-18）；v1 从最早的 v0.8.4rc1 起一直存在。
- **至 v0.30.0rc1 / v0.30.0，V2 仍未默认开启**：开关 `VLLM_USE_V2_MODEL_RUNNER` 存在且默认 False
  （v0.30.0 起 vllm 侧改为 `bool | None = None` 由 config 决策），Ascend README 仍标
  `[Experimental]`；v0.30.0 官方 Notice 明确“仍默认 v1、计划下个版本全面切换”。
  回答“v2 默认开启版本”时只能给 unknown/计划，不能猜。
- 本地 vllm 克隆缺少部分 tag（如 v0.12.x），因此配对**优先读 vllm-ascend 自身的
  `versioning_policy.md` 兼容矩阵**；矩阵缺行才回退 tag 推断，并在 `pairing_basis`
  里标明。上表 `-` 表示该 tag 内矩阵尚无该行，可用最新 tag 的矩阵补。
