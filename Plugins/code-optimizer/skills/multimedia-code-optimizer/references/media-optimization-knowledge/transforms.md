# DCT、IDCT、FFT 与小波

## 蝶形与量化尺度

变换矩阵行具有对称/反对称系数时，先计算镜像输入对 `x[i]±x[N-1-i]`，分解偶奇部分并复用和差，减少常数乘法；预加减多留一位。二维多行并行→转置→第二维，保持两维间原有缩放节点。

变换输出只供量化消费时，可省去变换末尾的归一化，将 `F'=s[u,v]F` 的尺度折入 `Q'=s[u,v]Q`；AAN 类缩放变换用此方式减少乘法。预存逐位置倒数与修正，表精度及中间舍入共同决定量化阈值，不能仅凭实数尺度相消判定整数路径等价。

反量化加载时计算 `coef*Q`。已有非零掩码选择：全零填基线/复制预测；仅 DC 广播常量，正交归一化 N×N IDCT 为 `F00/N`；某列仅首项非零时第一维广播、第二维继续。固定稀疏输入删除恒零支路，存活路径保留舍入。

## 输出裁剪

只消费 U×V 时，第一遍 `T[y,u]=R1(Σx H[u,x]X[y,x])`，u∈U；第二遍 `F[v,u]=R2(Σy G[v,y]T[y,u])`，v∈V。R1/R2 为原节点的移位、舍入与裁剪。点积只取目标矩阵行；蝶形从目标输出反向标记依赖，保留共享和差。

临时区 `T[y*|U|+j]` 对应 U[j]，同步修改转置与 stride；写回原频率位置，定义为零的省略区域清零。N×N 直接矩阵变换仅取 U×V 时，乘法量为 `N²|U|+N|U||V|`，临时元素为 `N|U|`；蝶形收益取决于删除输出后仍需保留的共享支路。

## FFT 与频域卷积

固定长度复用计划、旋转因子与置换；1、−1、±i 化为符号改变和实虚交换。实输入用 RFFT；二维按行→分块转置→另一维，沿变换方向使用对应归一化。

固定卷积核频谱跨块复用，输入 FFT→频域乘积→逆 FFT。线性卷积各维补到至少 `输入长度+核长度-1`；长输入 overlap-add 累加重叠区，或 overlap-save 丢弃循环污染前缀。

### 插零升采样的短频谱复制

L 倍插零的 N 点 DFT 等于原序列 `N/L` 点 DFT 的 L 次周期复制。先对未插零的样本做短 FFT，再复制频谱，接原来的 N 点滤波乘积和逆变换；实输入的短频谱按共轭对称关系展开。

保持原滤波核、采样相位、块重叠及正逆变换归一化，改变的只是正变换的计算方式。不生成大量零输入，也不对它们执行长 FFT；全部频带及抽头仍参与计算。

### 零相位对称核的实数频谱乘法

实偶对称核以零时刻为中心，负时刻抽头环绕到块尾，其频谱为实数。输入频谱保持 FFT 原生的实部／虚部向量布局，直接计算 `Yre=Xre*Hre、Yim=Xim*Hre`，同一个核向量供两路复用。

普通复乘的四次实乘、两次加减缩成两次实乘，也省去为了标准频序而做的重排。逆变换的 `1/N` 可预先折入核频谱。实变换打包的 DC 与 Nyquist 槽分别相乘；Nyquist 是独立实频点，不属于可清零的普通虚部。
