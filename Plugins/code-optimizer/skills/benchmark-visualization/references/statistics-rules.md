# 统计规则

每幅图按 facet、series 和 x 分组。指标统计由统一统计函数计算，渲染不重新选择样本。

- 不聚合的散点展示所有观测；折线、柱状、点估计和热力图遇到重复 x 时要求显式聚合或通过 series 区分运行。
- mean 是等权观测平均；不同时间窗口、请求数或权重需要上游按明确口径汇总，不默认加权。
- std 使用样本标准差，ddof=1；不足两条时报错。mean±SD 的范围在不足两条时留空。
- MAD 是 median(abs(x-median(x)))，不乘缩放系数。
- 分位数使用排序位置 (n-1)*q 的线性插值。
- min/max、IQR、SD、MAD 是描述性范围，不是置信区间。IQR 可能不包含用户选择的中心统计量，图中分别呈现范围和中心。
- 已有 min/max/median/p99 输入应声明 sample_level=summary。直接画这些值是允许的；再次聚合必须 aggregate_summary=true，并在标签中解释是“各轮统计值”的聚合。
- 五次运行中各有一千次采样不等于五千次独立运行。unit_id 检查只能阻止同一组内重复编号，独立性本身仍依赖实验设计。
- 不根据慢值自动删除样本，不用波动范围自动判断显著性。失败轮和预热数据应由上游状态字段表达，用户过滤后配置记录保留。
- IPC 等比率的跨轮平均与总计数之比不同；脚本只按用户提供列作图，不替用户选择因果解释或派生公式。

summary.json 中 source_rows 对应适配后零起始记录索引；vector 记录还保留原 source_index。data 下 CSV 保存图中全部观测，配置保存筛选和聚合操作。
