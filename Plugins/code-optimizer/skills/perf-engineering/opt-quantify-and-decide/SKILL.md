# 量化 + 决策（阶段 5）

## 何时使用

- 优化镜像/改动已就绪，要和新基线做对比。
- 需要判断"涨了 4.6% 是不是噪声""是不是少干活了"。
- 需要把保留结果固化成下一轮的基线。

## 核心原则

1. **N 轮取中位，口径书面固定**：增益 = `(新值 − 基线) / 基线 × 100%`；**吞吐正数=提升、时延负数=改善**，写死正负号语义。
2. **硬门禁（如吞吐 >+3%）是"必要但非充分"条件。** 过门槛 ≠ 能留。
3. **p50/p95/p99 全方向都要看**，尾延迟回退要并列反馈。
4. **防"假提速"要两层铁证**：量（干了一样多的活）+ 质（每个请求干得一样重）。
5. **门槛只筛底线，真正的取舍在决策层**：把代价量化到便于决断的单位，由业务语义拍板。
6. **决策要固化到可执行配置**：下一轮的基线 = 这一轮的保留结果，不靠操作者记性。

## 步骤速览

标定案例逐轮值、中位可复算说明、噪声判定与决策记录**只在 `references/quantify-decision.md` 一处维护**，
本节给步骤名与去向：

1. **固定对比口径**——3 轮取中位；基线 = 当前 kept 配置；写死增益公式与正负号 → references §1。
2. **防假提速两层铁证**——量（请求计数逐位一致）+ 质（底库计数 + 实际响应命中数 + 结果 ID 对齐）→ references §4。
3. **全方向看指标**——吞吐/p50/p95/p99/相位时长 → references §3。
4. **噪声判定**——交替复测 + 逐轮差值估计不确定性，比两组分布；证据不足保留"待定" → references §5。
5. **代价量化 + 决策**——把代价换算成可决断单位，业务语义拍板 → references §6。
6. **无效时先问"能不能干净归因"**——查混杂，无法归因就诚实降级 → references §7。
7. **固化决策**——镜像/参数钉进单一入口，作废项反向还原 → references §8。

## 门禁

- [ ] 3 轮中位 + 口径书面固定
- [ ] 请求计数与基线逐位一致、错误为 0（量）
- [ ] 语义正确性核验通过：底库计数 + 实际响应命中数 + 结果 ID 对齐（质）
- [ ] p50/p95/p99 全看，尾延迟回退已量化且两侧同口径毫秒值齐全（缺失标待补测）
- [ ] 交替复测 + 逐轮差值估计不确定性，比较两组分布；证据不足保留"待定"而非硬判增益/无增益
- [ ] 混杂因素已排除或已诚实降级
- [ ] 决策已钉进可执行配置，入口已指向 kept

## 产物

- 测量报告（逐轮值 + 中位对比表 + 增益/代价）
- 决策记录（保留/放弃 + 理由 + 代价）
- 已固化的配置快照
