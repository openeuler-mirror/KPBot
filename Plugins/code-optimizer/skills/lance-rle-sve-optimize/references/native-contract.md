# RLE 原生接口与初始化协议补充

## 输入支持范围

历史内核适用于 u32/u64 值与 U8 次数，不允许将 U16/U32 次数按字节伪装成 U8。其他条件保留原路径或分别实现、验证。严格 block 与 clamp miniblock、Flat 与压缩子缓冲分别覆盖。

## 初始化和错误

调用前检查元素/字节大小及输出容量，保持简单值 Vec 长度为零，初始化前缀参数置零。C 维护连续已写元素数，并在每一条返回路径按协议发布，错误不能留下不准确的前缀。

Rust 接收后验证状态、前缀未超出 N，成功还要求恰好写满 N，然后才设置输出长度。未知状态、超限或成功但长度不足均不能直接暴露结果。计数是元素数，不是字节数。

u32/u64 的长度零 Vec 在错误时直接丢弃，不必额外建 Drop guard 或为了清理设置部分长度。返回值检查无法补救已经发生的原生越界，需要证明存储边界并在目标上进行适当内存检查。

正常不适用回退发生在原生执行前。原生失败后若为重建错误调用 Rust，而 Rust 成功，就应报告候选问题，不能将其变成成功候选成绩。

## 指令与线程向量长度

检测实际需要的 SVE/SVE2 与系统能力。AArch64 不代表 SVE，SVE 不自动代表 SVE2，获取长度的辅助函数也不能在检测前执行可选指令。全局编译参数需要单独核查。

SVE 长度可能因线程而异，应在执行上下文得到通道数量。每个已测试长度分别覆盖 u32/u64、向量边界、末段不足、U8 的 255、合法空输入、次数异常及部分写入后错误。没有测到的长度或回退平台明确标为未测。
