# 定点与内核数据流

## 常数与偏置

同一舍入区间内，`a*(x+y)+b*y=a*x+(a+b)*y`、`a*(x-y)+b*y=a*x+(b-a)*y`；预合并常数，按点积分组交织输入。`A(x-z)+b=Ax+(b-Az)`，参数更新时计算偏置；零和滤波器不修正，仅 DC 基非零的变换只改 DC。

点积偏置用 `Σ(x−z)c=Σxc−zΣc` 移出内循环。双方带偏置时，`Σ(x−zx)(c−zc)=Σxc−zcΣx−zxΣc+n*zx*zc`；常量侧和预计算，动态侧和并入打包。u8 转有符号字节可翻转最高位表示 `x−128`，宽累计补回 `128Σc`。

对 `R(v)=floor((v+bias)/2^k)`，整数 m 满足 `R(v+m*2^k)=R(v)+m`；整倍数偏置可跨该移位，跨饱和节点限于未截断区间。

固定除数：`0≤n<2^w、2≤d<2^w`，预存 `m=floor(2^w/d)`，取 `q0=high_w(n*m)`、`r=n-q0*d`，精确商为 `q0+(r≥d)`。乘积取 2w 位；d=1 直通，二次幂移位。对称量化先宽化计算 `abs(c)+floor(d/2)`，求商后恢复符号。

## 差分位图压缩查表

单调递减整数表的平缓区，相邻项只差 0 或 1 时，每八项存一个最小值 M 和一个变化位图 D。位图从高位到低位记录组内各位置之后是否下降；查询 `h=x>>3、l=x&7`，以 `M[h]+popcount((D[h]<<l)&255)` 重建值。变化大的前段另存直接表。

用分段基值和位图代替完整表，查询时以移位、位计数和加法精确重建。SGR 的寄存器布局与指令组合见 [NEON 实现](../arm-simd-optimization/arm-neon-methods.md#差分位图压缩查表)。

## 位宽与归约

单累加链受依赖延迟限制时，将求和项分配到多个独立累加器，末尾合并，初值与偏置只计一次。链数按延迟、吞吐和寄存器余量选择；短循环或出现 spill 时减少链数。每条链及最终合并均需满足位宽；逐步舍入、饱和的累计不能直接拆链，浮点拆链需允许改变求和顺序。

输入在 [L,U]、`P=Σmax(c,0)、N=Σmin(c,0)` 时，点积范围为 `[LP+UN,UP+LN]`。像素先扩宽求差，平方与成对乘积和分别选宽度；两个 s16 乘积相加可能达到 2³¹。

算术右移 `(x+2^(n-1))>>n` 为半值向正无穷舍入，整数除法向零截断。整数改写保留中间舍入、饱和节点；浮点重结合和 FMA 采用对应数值路径。

## 融合与布局

生产者与消费者按小组融合，中间值留在寄存器，消除 N 个 b 字节元素的一次写回和读入，共 `2Nb` 字节；保留原舍入、裁剪节点，寄存器压力导致 spill 时缩组。消费者沿生产者的自然输出布局计算，逐元素参数表同步重排，仅在需要自然顺序的接口恢复；邻域或扫描操作需同步调整索引，不能只重排参数。

同参数独立块合批，每 lane 放不同块的同一位置，减少块内重排与水平归约；布局能跨阶段复用时更值得采用。尺寸、位深、模式在批入口选核，结果按原序供预测与熵状态消费；打包和还原成本计入比较。

尾部复制有效输入到暂存区，按边界补 halo，运行同核并只回写有效输出；RGB24 按 3r 字节复制，下采样按组计算长度。bias/查表后再屏蔽无效归约项：和补 0、min 补最大值、max 补最小值；位置偏置延续全局相位。

ISA 与线程 VL 选择见 [ARM 库](../arm-simd-optimization/INDEX.md)。

## 改写循环以形成向量数据流

| 受阻形态 | 具体改法 |
|---|---|
| 单累计器串行依赖 | 按[位宽与归约](#位宽与归约)拆分独立累计链 |
| 每个输出都做一次水平归约 | 将相邻输出映射到不同 lane，归约维改为循环；每轮广播一个系数，向多个输出累计，最后直接向量存储 |
| 输入与输出指针可能别名 | 在确实不重叠的内核接口表达 restrict；同时支持重叠时，在循环外判断范围并分派到非重叠向量路径与保序路径 |
| 循环内逐元素条件更新 | 将条件变成比较掩码，用 select 或谓词更新；条件归约先把未选元素置为归约单位元，最后统一归约 |
| 每轮重复判断固定模式 | 将整次调用不变的格式、符号性、系数类别分支移到循环外，分别进入无该分支的专用循环 |
| 多阶段混在一起阻止向量化 | 将带真实递推依赖的阶段与独立逐元素阶段拆开，以局部块传递中间量；独立阶段单独向量化 |
| 内层跨行或跨结构大步长访问 | 交换独立循环，使连续维位于内层；需要复用另一操作数时按小块交换，在块内广播或寄存器转置 |

## 减少数据搬运

| 数据流 | 具体手段 |
|---|---|
| 同一输入参与多组输出 | 输出按寄存器可容纳的大小分块，每次加载更新多个输出累计器；累计完成后一次写回，缩小块直到内层不再 spill |
| 内核反复按固定顺序读取非连续数据 | 按内核的实际消费顺序 pack，内层顺序读取；常量权重预打包并跨调用复用，动态输入按消费块打包 |
| 输出块跨较长归约维反复读取输入 | 分层划分输出维与归约维：寄存器保留微块累计器，缓存块保留重复使用的输入面板；块大小计入同时存活的输入、输出和打包缓冲 |
| 中间结果只被下一阶段使用 | 按[融合与布局](#融合与布局)直接传递中间量 |
| 相邻块需要重叠的中间行 | 使用[行环](filters.md#行环box-与行带)保留仍需消费的行 |
| packing 同时需要统计或数值转换 | 在同一次读入中完成布局转换、行列和及所需类型转换，避免单独扫描；下游直接消费最终打包格式 |

## 成组检测后简化计算

需要检测一组整数是否全零时，先将多向量按位 OR 合并，再归约或提取合并结果判断，减少逐向量分支。按非零分布选择完整核、部分项核或直接填充；只有固定少数项非零时，保留这些项的贡献并跳过其余乘加。

按多个 lane 的条件选择昂贵路径时，先形成比较掩码，再区分全不满足、全满足和混合块；前两种使用整块跳过或无逐元素选择的专用路径，混合块再按掩码处理。
