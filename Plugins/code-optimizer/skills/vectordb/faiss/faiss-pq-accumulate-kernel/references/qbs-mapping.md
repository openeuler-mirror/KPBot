# qbs 映射

## 语义

qbs 是半字节（4 位）序列，每个半字节是一次内核调用的 NQ（该组查询数），组数由编码位宽与取值范围决定、无固定上限——如上游 preferred 表对 13 个查询产出 0x13333，按低半字节起解码为 3、3、3、3、1 五组。qbs → nq 的换算与"preferred qbs"查表函数是把可用查询数映射到分组形态的入口。

## 映射选择

- 通用映射倾向"每步 3 个查询"的多步形态：源于窄寄存器 ISA 上 NQ=3 已接近预算。
- 预算更宽的层可以承载更大的单步 NQ（如 4/5/6），减少步数与调用开销；此时应提供该层自己的 preferred 映射表，而非复用通用表。
- 映射表是候选而非结论：逐层实测各 qbs 形态的每元素成本后再定表；表中未覆盖的 qbs 走通用回退。

## 实现要点

- 层级专属映射与通用映射并存时，分派处按层选择；两层映射都必须有完整的实例化（编译期 switch 覆盖所有表项 + default 抛错或回退）。
- 输入校验：按实际编码位宽、取值范围与内核支持的组形态校验，不设固定组数上限；查询数为负或超范围在入口拒绝，避免位运算静默截断；受支持但没有专用映射的形态交给通用路径。
- 改映射不改语义：任何 qbs 形态下结果集与逐查询路径一致；用同一保存索引对照。

## 测量

- 扫描 qbs 值域，报告每形态的每元素周期数与 spill 情况；曲线平顶处即为该层最优 NQ。
- 查询数不足整组时记录尾组处理成本；映射表应尽量减少尾组浪费。
