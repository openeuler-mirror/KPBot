# 里程碑甘特图

用户要填表时，提供[事项和时间窗模板](assets/事项和时间窗.xlsx)的副本。两张工作表内的记录都是可替换的示例。用户已提供工作簿时，直接使用该文件生成。若表头不同但对应关系明确，可整理到模板副本，保留原文件。日期、完成率或里程碑含义不清时，指出具体行和需要核对的值。

## 输入约定

- **事项**每行一件事。「事项名称」「开始日期」「截止日期」必填，首尾两天均计入。「负责人」「状态」「完成率」可空。状态留空按「待更新」显示。状态可选未开始、进行中、受阻、待验收、已完成、待更新。按实际信息填进度，如 Excel 百分比 `45%`。时间经过本身不能证明工作已完成。
- **里程碑**每行一个节点，填写「里程碑名称」与「日期」。一个里程碑只占一个日期，可列多个同日节点。没有里程碑时可将此页留空或省略。两个表的表头均在各自前十行内。日期可用 Excel 日期或 `YYYY-MM-DD` 文本。

## 生成与交付

可将整个技能目录复制到其他 Agent 的技能目录。具有本地文件和命令行权限的 Agent 也可直接运行生成器。工作目录可以是任意目录，以下命令仅为简写，假定当前目录是本技能目录。使用 Python 3.10+ 和 [requirements.txt](requirements.txt) 中的依赖。优先选用宿主已提供的、含 openpyxl 的 Python 解释器。在新环境的虚拟环境中可运行 `python3 -m pip install -r requirements.txt`。

```sh
python3 scripts/generate.py "/path/to/排期.xlsx" --output "/path/to/项目甘特图.html" --title "项目交付进度"
```

- 默认按浏览器的本地日期显示「今天」。只有用户指定历史或未来基准日时才加 `--as-of YYYY-MM-DD`，图中会注明该日期。
- 输出是可离线打开的单个 HTML 文件。里程碑和日期位于上方，各事项的时间窗和进度位于下方，使用同一条时间轴。输入 Excel 更新后重新运行即可刷新。
- 成功返回退出码 0，并在标准输出给出 JSON，含 `output`（绝对路径）、`tasks`、`milestones`、`as_of`（动态今天为 null）。失败信息在标准错误。核对条数后把 HTML 链接交给用户，并说明所用基准日。使用模板演示时，在图名和交付说明里标明「示例」。

可在技能目录运行 `python3 cases/workbook-render/run.py` 自检。用例核对模板生成的 6 项事项和 3 个里程碑，并验证日期逆序和输出路径不可写入时保留已有图表。结果写入当前目录的 `results/result.json`。
