# FastScan 参数与数据布局

## Packed code

PQ4 路径每个子空间 4 位，但块存储可能为对齐、偶数子空间或块尾增加填充。通过实际 packer、code_size、bbs 和 BlockInvertedLists 确认地址计算；紧凑码字的逻辑大小不能直接充当物理块步长。

## LUT 与累加

查询侧通常先生成浮点 LUT，再量化并保存缩放/偏置，重排为适合 SIMD 查表的形式。核对 LUT 元素类型、表长、饱和规则、整数累加上限和最终距离恢复，避免溢出或改变结果排序。

## 调度参数

- bbs：码字块大小，支持值及内核限制由实际实现确定。
- qbs/qbs2：query 分组或分组上限；单 query 与批量 query 的 setup 摊销可能不同。
- implem：实现选择器；自动值不等于实际执行路径，记录解析后的选择。
- result handler：heap/reservoir 的阈值维护与最终排序。

## 边界

覆盖非整块、奇数子空间、少量 query、不同 top-k、非有限表值和 handler 切换。仿真/标量验证路径仅在源码提供且数值契约匹配时作为参考。改变块大小、批量或实现选择应与纯内核改写分别实验。
