## 检索

先查两个主题索引，再按目标代码的计算模式、数据流和瓶颈搜索整个库，结合算法名、算子名、别名及等价计算模式补充检索。同一对象在算法、共用方法、标量、NEON、SVE、SVE2、SME 中的相关章节都读一遍，沿交叉引用补齐，不按目标 ISA 提前排除其他实现。算法名不明确时从滑窗、点积、归约、前缀、查表、位流或状态递推检索。

对照计算简化、输入复用、布局、累计与重排，综合各方法优势，再映射到目标平台。保留位宽、舍入、边界、复用范围及指令语义前提，区分精确变换、近似与启发式方法；参数按输入和资源条件推导。

检索结果给出方法、关键公式或变换、成立条件与条目链接。未覆盖的内容再查规范、架构资料、论文或源码，区分已有证据与待验证推断。
