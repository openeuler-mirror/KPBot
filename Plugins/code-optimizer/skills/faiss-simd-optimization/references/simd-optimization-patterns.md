# SIMD 改写与验证

- 多累加器/展开：在隐藏依赖延迟与寄存器、代码体积之间取舍，覆盖尾部；不改变每条要求保持的 FP 累加链。
- 查表：比较 gather、寄存器查表和索引构造总成本，验证 lane 映射、表边界与 VL 约束。
- 数据搬运：合并加载或替换 lane 构造时核对对齐、alias 和合法读取长度，避免为了宽加载越界。
- 预取：距离、hint 和批量根据访问时序与实际 cache 测试，不预设某个平台的最佳 ahead。
- 融合/缓存：一起测量 setup、临时存储和主循环，说明生命周期及并发所有权。
- 归约：减少归约次数可能改变加权、精度或溢出行为，逐项证明等价并实际对照。

每个候选先小范围验证指令形态与功能，再用完整冻结负载确认整体效果；微基准改善不能替代系统性能证据。
