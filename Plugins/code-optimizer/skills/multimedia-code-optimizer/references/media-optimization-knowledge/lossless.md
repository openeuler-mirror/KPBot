# CABAC / ANS / 无损编码手段

## CABAC

H.264/HEVC 将概率状态转移、LPS range 和归一化移位制成小表；range 更新后查移位数，一次移位代替逐位循环。位缓冲充足时连续处理多个 bin，仅在不足时 refill。regular、bypass、terminate 分开内核；bypass 仍推进算术状态。

## ANS

rANS 总频率 `M=1<<R` 时，将各符号的累计频率区间展开成 M 项解码表，以 `u=x&(M-1)` 一次取得符号、频率 f 和偏移 `u-c`，更新 `x=f*(x>>R)+(u-c)` 后按码流归一化。tANS/FSE 将符号、消费位数 n 和下一状态基值 b 放入同一表项，更新为 `state=b+read_bits(n)`；频率固定时复用表。

码流已有交错独立状态时，穿插各状态的查表、更新和 refill，隐藏单状态依赖；不能自行改变状态与字节消费顺序。表项字段按取值范围压紧，减少表空间和加载次数。增大 R 会细化频率量化并扩大表空间，编码端选 R 时同时考虑压缩率与缓存占用。

### FSE 归一化阈值的高位编码

设表对数为 R、符号频数为 f>1，预计算 `k=R-floor(log2(f-1))`、`Δ=(k<<16)-(f<<k)`。对状态 x，输出位数直接为 `n=(x+Δ)>>16`：状态是否越过归一化阈值，由加法高位给出，不再单独比较或循环移位。

输出 x 的低 n 位后，以 `(x>>n)+C-f` 索引状态表，C 是该符号之前的累计频数。每个符号只需保存 Δ 和 `C-f` 两个常数。频数为 1 时，Δ 取 `(R<<16)-(1<<R)`，索引偏置为 `C-1`，继续使用同一个编码内循环。

## Rice / RLE / LZ

- Rice：非负 x 用 `q=x>>k`、`r=x&((1<<k)-1)`；按位序用 clz/ctz 搜索一元码终止位，跨字时累加商，最后读 k 位余数。
- RLE：向量比较相邻元素→提取变化掩码→逐个取置位位置，相邻位置差生成 run length；块间携带末值与未结束长度。
- LZ 匹配：短前缀哈希定位候选，宽字 XOR 后按端序找首个不同字节，推进匹配长度。
- LZ 复制：长距离连续块复制；短距离用种子模式扩展，保证本次生成的字节可被后续复制读取。

## LZ 匹配搜索与解析

已有最佳长度 L，仅寻找更长匹配时，先检查候选与输入的第 L 个字节（零起算）以及短前缀；任一不符即可跳过完整比较。先保证该探测位置落在有效前瞻范围内。通过早筛后用宽 XOR 找首个差异，匹配长度限制到剩余输入与格式上限；哈希相同仍需验证字节。

哈希桶链接历史候选，按由近到远遍历，距离超出窗口时停止。设置最大遍历节点数限制最坏耗时；达到足够长的匹配时提前结束，已有较长匹配时缩小链搜索预算。前缀和第 L 字节淘汰在最长匹配目标下是精确早筛；节点预算与足够长阈值会改变搜索结果。若同时优化距离码价，较短或同长度但更近的候选仍可能有用，不能全部套用“必须超过 L”的早筛。

Lazy matching 暂存位置 i 的匹配，再搜索 i+1；后者更有利时输出 i 的字面量并延后匹配，否则提交 i 的匹配。简单路径比较长度；码率路径在共同结束位置比较“当前匹配＋后续代价”与“一个字面量＋下一位置匹配＋后续代价”，计入长度码、距离码及附加位。跳过的位置按既定策略更新哈希字典，避免后续候选集合意外改变。

给定固定符号码价时，可做有界最短路径解析：位置 i 的字面量边到 i+1，长度 L 的匹配边到 i+L，分别加字面量或长度／距离代价，更新累计最小成本与回溯边。候选按长度与距离码价去除被支配项；限制前瞻长度控制状态量。动态码表先用估计码价生成解析，再据统计更新码价重新解析，不能把首次估计当作最终实际位数。
