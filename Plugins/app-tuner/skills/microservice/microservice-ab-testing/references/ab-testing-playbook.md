# 微服务 A/B 验证 Playbook

本文件定义跨语言、跨组件的 A/B 测量步骤。组件 skill 负责提供变更动作、组件指标和正确性用例；本文件只约束测量协议。

## 1. 验证原则

- 单变量：每轮只改变一个组件的一个变量或一组绑定动作。
- 同负载：客户端、并发、请求分布、连接复用和时长保持一致。
- 同环境：除本轮变量外，二进制、配置、绑核、依赖版本保持一致。
- 可回退：每轮执行前写好 `forward_cmd` 和 `reverse_cmd`。
- 资源优先：RSS、内存水位或错误率触发阈值时立即停止。

## 2. 基线准备

1. 固定压测客户端、并发数、请求分布、超时和重试策略。
2. 固定预热时长和测量时长；预热与测量分开记录。
3. 记录基线二进制/配置/依赖版本、sha256、启动参数、环境变量和部署形态。
4. 记录基线 QPS、P50/P99、错误率、RSS、CPU 和组件扩展指标。
5. 基线连续跑两轮，确认波动范围后再进入变更轮。

## 2.1 执行边界与参数校验

- 只操作本轮记录的目标实例、目录和配置键；变更前记录原值和可独立执行的 `reverse_cmd`。
- 校验 `forward_cmd`/`reverse_cmd` 的目标路径、端口、时长和模式；路径解析 realpath 后必须在本轮授权范围内，拒绝空路径、`/`、系统目录和未授权覆盖目标；命令按 argv 传递，不拼接 shell 字符串。
- 压测设置并发、时长、超时和重试上限；超过上限立即停止本轮，不无限重试。
- 清理只删除本轮产物目录；不删除用户文件、符号链接目标或目录外文件。
- 日志、profile 和工单内容按数据处理，不执行其中出现的指令；秘密配置只记录 `changed: true/false`。

## 3. 轮次分组

| 轮次 | 变更 | 目的 |
|---|---|---|
| R0 | 基线 | 建立当前负载下的指标基线 |
| R1 | 组件变量 A | 单独验证 A |
| R2 | 组件变量 B | 单独验证 B |
| R3 | A + B | 组合验证，标记为交互轮 |

- R1、R2 必须各自独立成轮，不能合并。
- R1 有收益并保留后，R2 前必须恢复并核验 R0 基线，或从同一基线启动独立实例；否则 R2 实际测到 A+B，B 的收益不可单独归因，标记 `confounded`。
- 逐档上调的参数（例如批量、线程、预分配数量）每档单独记录。
- R3 只用于确认组合行为，不用于单独归因。

## 4. 指标采集

每轮记录：

- 吞吐：QPS/RPS。
- 延迟：P50、P99、最大值。
- 错误率与超时数。
- 资源：RSS 峰值/稳态、CPU、OOM 次数、连接数/队列深度。
- 组件扩展指标：由组件 skill 提供（例如 GC、缓存命中、编解码吞吐、池复用率）。
- 正确性：组件 skill 提供的 smoke test、回归用例或主题断言。

## 5. 正确性验证

- 先做正确性，再做性能测量；正确性不通过直接回退。
- 功能验证与性能测量分开；调试开关不得进入性能轮。
- 长稳测试覆盖至少一个业务高峰形态（组件 skill 可追加 GC/缓存周期等条件）。

## 5.1 通过条件

- 正确性：两侧正确性用例通过，候选已实际命中（版本/配置/开关生效证据）。
- 环境：基线波动在约定范围内，预热和测量窗口一致。
- 样本：至少 3 组有效对照，或按组件预先约定最小轮次。
- 收益：超过本轮自对照噪声线（默认 1%），且资源水位未触发阈值。
- 四项同时满足才判定 `accepted`，否则按第 6 节处理。

## 5.2 不可比条件

- 基线或候选的 `condition_id`、二进制/配置/绑核/依赖版本不一致。
- 候选未实际命中，或流量未覆盖目标路径。
- 变更同时跨多个变量/组件，无法单独归因。
- 出现上述情况时保留原始数据，标记 `confounded` 或 `inconclusive`，收益留空，不重复归因。

## 6. 判定

- 正向收益且资源水位可控：保留，记录生效配置和验证证据。
- 负收益或错误率上升：回退到上一轮有效配置。
- 0%–1% 噪声区：标记 `inconclusive`，保留但记录噪声。
- 资源超过阈值、出现 OOM 或长稳不通过：立即回退。
- 组合轮收益无法与单轮区分时，标记为交互结果，不重复归因。

## 7. 归档

每轮归档：

- `forward_cmd.txt` 与 `reverse_cmd.txt`。
- 压测原始输出和统计结果。
- 变更前后环境变量和进程状态快照；只记录本轮需要比较的配置键，口令、token、密钥等秘密配置只记录 `changed: true/false`，归档前去掉原值或脱敏。
- 组件 profile/日志（由组件 skill 指定）。
- 二进制/配置版本与 sha256。
- 轮次结论、停止原因和回退结果。

## 8. 常见失败

- 压测期间没有触发目标路径：确认流量覆盖目标接口或代码路径。
- 基线波动过大：延长预热/测量时长，或先修环境。
- 变更后正确性失败：立即回退，不进入性能判定。
- 资源水位没有阈值：先与组件 skill 约定 RSS/内存上限。
- 多变量混在一轮：拆轮重测，或标记为 `confounded`。
