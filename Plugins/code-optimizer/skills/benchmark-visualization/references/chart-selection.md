# 图表选择

| 目的 | 图型 | 建议 |
| --- | --- | --- |
| 独立实验波动 | scatter / box | 展示所有点和样本量；小样本优先散点 |
| 随规模/线程/时间变化 | line | 横轴设 numeric；按版本或运行编号分线 |
| 中心与范围 | point / line + spread | 明确聚合方式和范围意义 |
| 类别或版本对比 | bar / point | 多系列自动分组；多单位分成多图 |
| 请求或运行分布 | hist / ecdf | 指明样本层级；直方图共用分箱 |
| 两维配置矩阵 | heatmap | 缺失格为空，不填零 |
| 多硬件或多数据集 | facet | 任意数量分面；用 columns/figsize 控制布局 |

修改纵轴时设置 ylim；只固定下限可用 [0,null]。手动范围可能裁掉数据，交付时检查并在说明中注明。对数轴不能接收非正值，需要时使用线性或 symlog。

重叠散点可调 point_size、alpha 或拆成分面。本版不自动抖动或下采样，全部观测保留；特别大的数据集先协商显示策略。组数较多时扩大 figsize、移动 legend_loc 或进一步分面，不限制固定组数。

hist/ecdf 按 facet 和 series 绘制所有选中值的分布，不按 x 再分组；需要比较不同线程/规模的分布时将该维度加入 facet 或 series，或通过 filter 固定。跨配置混合分布只在用户确实需要描述该混合样本时使用，不能称为固定条件下的实验波动。

箱线图离群点只表示绘图规则中的特殊点，不代表测量无效。首版暂不提供小提琴、双轴、堆叠、Gantt、自动置信区间、按点大小映射第三指标；不要将扩展计划当作已支持参数。

长类别名称自动编码并附全称映射。无读图能力的 Agent 只核对数据、配置和产物路径，将视觉审核交给用户，不调用图像读取工具。改图可在同目录通过 output.run_name 区分版本。
