# AArch64 标量指令手段

| 计算模式 | 指令手段 | 实现要点 |
|---|---|---|
| 整数乘法后加减 | MADD / MSUB | 把乘积作为单次加减输入；保持所需位宽，低位回绕计算与扩宽计算分别选指令 |
| 32 位乘积累计到 64 位 | SMADDL / UMADDL | 在源码中先扩宽操作数再乘加，避免先做 32 位溢出乘法；按符号选择形式 |
| 固定除数或重复使用同一除数 | UMULH / SMULH 加移位与修正 | 取 64×64 乘积高半代替除法；常量除数交编译器生成，运行时除数预计算对应乘数和修正参数 |
| 同一对操作数同时求商和余数 | UDIV/SDIV 后 MSUB | 先算 q，再用 `r=n−q*d` 复用商；避免两条独立除法路径 |
| 短数据相关分支 | CMP + CSEL/CSINC/CSNEG | 将安全且便宜的两侧表达式转为选择；不要为此无条件执行越界访存或昂贵计算 |
| 多个标量比较形成布尔条件 | CCMP/CCMN 链 | 利用条件更新 NZCV 合并比较，最终一次跳转或选择；内存访问仍遵循原短路条件 |
| 位段提取、插入、旋转 | UBFX/SBFX、BFI、EXTR/ROR | 用无符号掩码/移位或 rotate 内建表达连续位段；有符号字段用符号扩展提取 |
| 零计数、字节反转 | CLZ、RBIT+CLZ、REV | 用 clz/ctz/byteswap 内建；传统 clz/ctz 内建的零输入单独处理 |
| 标量位计数、最值〔CSSC〕 | CNT、CTZ、SMAX/SMIN、UMAX/UMIN | 启用目标 CSSC 后让内建或直接表达式选指令，减少转入 NEON 计数或额外比较选择；保留基线版本 |

**减少 GPR↔SIMD 搬运**：连续向量阶段保持中间值在向量寄存器中，最后才用 UMOV/SMOV 或归约取标量；循环内反复抽取单 lane 再插回时，改为 lane 运算或向量谓词。
