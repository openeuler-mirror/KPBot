# 向量检索实验方法

## 输入

基线与候选身份、工作负载矩阵、正确性要求、性能指标、运行资源和可复现命令。

## 执行步骤

1. 按 [测量契约](references/measurement-contract.md) 冻结源码、构建、数据、索引、查询与环境。
2. 在观察结果前声明预热、缓存、样本数量、顺序、异常处理和漂移阈值。
3. 每个候选包含一个主要改动；正确性通过后运行 A1–B1–B2–A2 等平衡序列。
4. 保留全部有效样本，报告两侧中位数、离散程度、每组漂移及正确性差异。
5. 分工作负载计算比值；只有同类指标和明确矩阵才计算收益几何平均。

## 输出

manifest、原始测量、比较摘要、质量与性能结论及适用范围。

## 约束

冻结字段变化意味着新实验。漂移或信号不足时报告不确定性；单负载结论仅适用于该负载。不得挑选最好结果或静默放宽正确性容差。
