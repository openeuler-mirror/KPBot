# 实验协议

## 冻结与切换

每个业务场景记录两套框架及版本、完整命令和参数、输入摘要、随机种子、工作量、并发、编译工具链、非候选选项、机器、CPU/NUMA 和资源配额、缓存复位、预热、计时边界、指标单位及方向。优化本身涉及的选项归入该优化的变更清单。原版代表本次优化全部关闭的业务状态。

每次运行保存实际启用集合、源码与构建摘要、运行标识、时间、环境观测、完成状态和日志路径。测试命令中必要的产物路径随配置变化，框架参数与输入保持一致。比较前审核配置差异是否恰好为预期优化集合。可控条件偏离时该比较不可比；同条件自然抖动进入波动分析。

优先使用可验证的运行开关或独立构建。配置切换后验证命中及关闭行为，执行同一正确性用例和容差。审计计数和调试采集在正式计时外执行。已有性能结果只有在场景、条件、配置身份及配对记录可追溯时才可复用。

## 矩阵与依赖

用户指定 N 个优化点，按顺序为 p₁…pₙ。S₀ 为原版，Sᵢ 为前 i 项。第 i 项测原版到单项、Sᵢ₋₁ 到 Sᵢ、原版到 Sᵢ。所有项独立且兼容时，共 2N 个配置和 3N−2 对不同对照，首项三格复用同一比较。

依赖项单独无法运行时明确标注所缺依赖。依赖顺序不合法时先和用户既定顺序核对，再形成可执行路径。互斥配置保留无法执行的说明，仍可测其他合法配置。将不可拆分机制作为一项时披露归因粒度。组合正确性必须重新核对。

## 测量与波动

采样前声明重复计划、统计量、异常处理、漂移检查及预算。可用原版自对照评估噪声。对照双方在可比时间窗口内交错或平衡分块运行，保持同等预热、复位和工作量。计时期间避免其他实验争用同一资源。并行业务本身按指定并发执行。

保留每块双方原值，逐块计算相对改善，再报告收益中位数、范围及样本数。耗时改善为 (对照−候选)/对照×100%，吞吐改善为 (候选−对照)/对照×100%。不同场景分别计算。零分母或缺失值记录原值和不可计算原因。

描述性范围与分位数按实际名称报告。置信区间需说明算法及独立样本单位，循环内重复不能当成独立试验。组合收益直接测量，局部收益和单项百分比不能用于推算业务总收益。

微小变化与自对照噪声相当、方向不稳定、区间跨零或样本不足时，在该格标明“可能存在波动，方向未定”及依据。缺噪声证据时写“波动依据不足”。变化可辨但低于业务门槛时注明“未达业务门槛”。工具产生的观察方向需结合自对照、环境及正确性证据确认。

漂移时检查负载、频率、温度、资源竞争等可用证据，恢复冻结条件后在预算内补测。保留旧样本及失效原因。预算耗尽保留未定结论。正式结果只使用预声明规则认可的样本，保留排除记录。
