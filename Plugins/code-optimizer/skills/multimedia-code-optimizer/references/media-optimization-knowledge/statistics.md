# 分类归约与积分图

## 小类别计数与残差

类别少且同时需要计数、残差和时，复用比较产生的负掩码 m：有效且 label=k 为 −1，否则为 0；`count[k]-=Σm`，从零累计 `negSum[k]+=Σ(v*m)`，末尾 `sum[k]-=negSum[k]`。用有符号点积累计残差与掩码，掩码扩宽保留 −1；ARM 映射见[SVE 点积](../arm-simd-optimization/arm-sve2-methods.md#组合使用的独立扩展)。累计位宽覆盖残差范围与样本数，类别多时比较私有直方图后合并。

字节标签、少类别统计可比较逐类掩码计数与分段直方图；ARM 映射见[少类别直方图](../arm-simd-optimization/arm-sve2-methods.md#少类别直方图)。

SAO 标签为 `sign(c-a)+sign(c-b)`，残差为 original−reconstructed；keys 按结果槽次序列出有效类别。尾部或邻点不可用位置使用有效类别域外的标签，避免谓词加载的零值被误计入零类别。

## 前缀与共享统计

向量 scan 依次移位 1、2、4…项相加，再加前组末项 carry。二维积分图将每行 scan 与上一行积分值相加，首行首列补零，矩形和取四角加减；累计位宽覆盖全图前缀和。大量不同矩形查询可摊销积分图构建与存储，固定滑窗优先比较滚动和；浮点树形 scan 改变加法次序。

一次读取共享 sum、sumsq、cross；平方先扩宽，min/max 连同索引归约并处理平值。邻边 `e[i]=sign(p[i]-p[i+1])` 只算一次，下一像素左符号为 −e[i]，移位复用并跨块传末符号；符号用宽减法或 `gt(a,b)-gt(b,a)`。
