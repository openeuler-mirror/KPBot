# 累加等价性

## 通用方案的隐含成本

pq4 类内核把每字节的低/高半字节查表结果（每库元素一个字节）累到 u16 累加器。打包累加的语义是 `Σ偶 + 256×Σ奇`：只有当偶字节和始终 < 256 时，`accu >> 8` 才等于奇字节和；偶字节和一旦溢出，进位会混入高字节——例如连续两次累加、偶字节各 200、奇字节均为 0 时打包和为 400，`accu >> 8` 得到 1，而真实奇字节和为 0。

因此：

- 任何回偏/提取公式都必须显式声明前提——要么通过累加位宽或独立偶/奇累加器避免进位，要么在公式中重建进位；不能默认 `>> 8` 取奇字节和。
- 等价性验证以独立奇/偶累加器（不经打包）为基准逐 lane 比对，用例必须覆盖进位输入（如上例）。
- 常规做法是把偶/奇字节改用各自独立的 u16 累加器，该取舍源于"无字节域移位/无成对加宽"的 ISA 约束，代价是每次提取多一遍移位与计算。

## 成对加宽累加

若 ISA 提供成对加宽加法（偶字节拓宽入一个累加器、奇字节拓宽入另一个），则可分别得到干净的低字节和与高字节和，回偏修正整段消失。改写义务：

1. 证明 lane 映射：偶字节对应低字节和、奇字节对应高字节和；对照基准是独立的奇/偶累加和（或原内核完成正确回偏后的结果），不是打包结果的 `(accu, accu >> 8)`——偶字节进位与 u16 回绕都会使该提取失真（如偶和 0、奇字节连续两次累加 200：真实奇和为 400，打包 u16 回绕后右移只得 144）。逐 lane 验证须同时覆盖低字节进位与高字节回绕。
2. 适用条件：仅限无偏置、无缩放的 LUT 字节段；带 norm 缩放尾段（scaler）的路径保留原方案或单独推导。
3. 溢出检查：每 lane 的和 = 累加次数 × 255，须给出累加次数上界并验证落在 u16 范围；分块提取时按块内次数计。

## 字节域半字节拆分

高半字节提取通用写法是"拓宽到 u16 再右移 4 再掩码"，因为部分 ISA 无字节域逻辑右移。若目标 ISA 支持字节域移位，可直接在字节域完成，省去拓宽与掩码链。改写义务：掩码值、饱和/回绕语义与原实现一致；对 4-bit 码无符号语义无歧义。

## 验证清单

- 逐 lane 对比：改写前后每库元素的累加中间值与最终距离一致（整数路径应精确相等）。
- 尾段：奇数 nsq、scaler 尾段、非整块时走原路径的部分与基线一致。
- metric 两类（L2/IP）与带偏置的表分别验证。
- 汇编证据：确认回偏/拓宽指令确实消失，而非被编译器另行重排。
