# P 与 D 环境对比

## 工作流程

1. 确认指定 P 和 D 两份不同的快照。核对 `collection_meta.json` 的
   `targets`、`role`、节点和采集时间，以及目标 `inventory.json` 是否存在。
   比较器会展开包内全部容器，因此每份包只接受一个对象。角色缺失、标为 `PD`
   或与用户提供的信息冲突时，先确认每份快照的角色并注明来源。
2. 核实两份快照是否来自同一套部署且采集窗口可比。不能确认时对比仍可用于
   环境排查，但须注明跨部署、跨时段或未知，不把结果当作本次部署的一致性结论。
3. 在父 skill 目录运行现有比较器，将 P 放左边、D 放右边；输出目录须为空或不存在。

```bash
python3 scripts/compare.py <P采集包> <D采集包> --out <PD对比目录>
```

4. 检查 `对比结果.json` 确实只含所选的两个环境和一个 P/D 组合。按来源和
   采集时间核对 `left`、`right`；同一份采集的目录和压缩包不能充当两侧。
   分开记录设计上预期的差异、待核实的差异和无法比较的项。缺少部署依据时，
   将启动参数差异列为待核实。

## 输出

记录 P/D 两侧节点、容器、角色来源、采集时间、采集包路径、部署与采集窗口的
可比性，以及对比状态（完成 / 部分完成 / 无法比较）和 `对比结果.json` 路径。
优先看软件栈、启动参数、配额和 HCCL/ASCEND 变量；敏感字段只引用名称和受限
证据位置。
