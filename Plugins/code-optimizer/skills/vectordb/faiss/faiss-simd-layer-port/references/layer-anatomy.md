# 定宽类型层构造

## 组成

在长度可变的向量 ISA 上做定宽特化，需要：

1. 定宽类型别名：以编译器属性把可变向量类型固定到目标宽度（如 256-bit），并给出 u8/u16/u32/f32 各视图。
2. 逐元素谓词：每个操作显式使用与元素数匹配的谓词模式（如 32×u8、16×u16、8×u32）；谓词宽度与类型宽度不一致是最常见的静默错误。
3. 加载/存储：谓词控制的 load/store，注意对齐假设与合法读取长度。
4. 操作映射：算术、比较选择、unpack/pack、zip/unzip、transpose、gather/tbl、成对加宽等；先盘点目标抽象（simd256bit 及各元素类型）需要的全部成员与自由函数，缺一即编译或链接失败。
5. 复用窄层：语义相同的操作可继承窄层实现或别名挂到新 level，零新核即可先跑通链接。

## 常见坑

- 类型双关（union 视图、谓词位模式转整数）依赖别名规则时，要么重构要么在受影响翻译单元声明宽松别名，并记录理由。
- 查表类操作需要 lane 偏置构造（如双 lane 查表用索引位或表内偏移），先证明 lane 映射再启用。
- 打印/调试辅助函数按定宽元素数写死，宽度变化时一并改。
- 不存在的操作宁可显式报错，也不静默退化成标量循环。

## 验证

- 单元素数与跨元素数的构造/提取往返一致。
- 与窄层实现对同一输入的逐元素比对。
- 未特化符号在链接期暴露，不等到运行时。
