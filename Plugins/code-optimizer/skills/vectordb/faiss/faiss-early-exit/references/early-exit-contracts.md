# 提前退出判决契约

## 判决类型

| 判决 | 形式 | 安全条件 | 证明义务 | 门禁 |
| --- | --- | --- | --- | --- |
| 堆顶阈值 | L2：距离下界 ≥ 堆顶最差值即跳过；最大内积：得分上界 ≤ 堆顶最差值即跳过 | 堆已满；比较语义含 tie；相等遵循原并列规则 | 界按 metric 取正确方向（L2 下界、内积上界） | 结果 ID/距离精确一致 |
| 量化误差界 | L2：估计距离 − 误差界 ≥ 堆顶最差值即剪枝（下界）；最大内积：估计得分 + 误差界 ≤ 堆顶最差值即剪枝（上界）；相等沿用原并列规则 | 界覆盖量化/估计误差 | 界对全部适用输入（查询与残差形态）有保证：推导或全覆盖包络，不得用采样分位数 | 无损路径：逐结果 ID/距离精确一致且 Recall 一致；权衡实验：单列质量门槛（预声明 Recall 目标与验证方式） |
| 块级边界 | 整块聚合下界超阈值即跳块 | 块内所有码共享该下界 | 聚合界的单调性 | 逐结果 ID/距离精确一致；命中率与节省记录 |
| 编码门限（如汉明/多义码） | 编码距离超门限跳过 | 编码距离与真实距离的单调关系 | 编码等价性论证 | 逐结果 ID/距离精确一致；门限参数冻结 |

## 证明方式

- 推导：由量化定义推出 |估计 − 真实| ≤ 界，对全部码字成立。
- 实测包络：仅用于独立的"速度/召回权衡"实验；无损路径的界必须对全部适用输入（查询与残差形态）有保证——推导得出或全覆盖包络，采样分位数加余量不构成保证。
- 禁止循环论证：不得用"剪枝后结果没变"反推界正确。

## 图遍历判决

- "跳过结果提交"与"跳过扩边"分别判决：节点进不了 Top-K 不代表它不是到达更近节点的中转点（HNSW 会把已发现节点加入遍历队列，不做结果堆阈值判断）。
- 跳过扩边须单独证明不影响经该节点可达的更优候选，否则只跳过结果提交、照常扩边。
- 验证用例：构造较远中转节点连接更近结果的图，确认判决开启时不丢该更优候选。

## 门禁与 worst-case

- 纯实现优化：逐结果 ID/距离一致 + Recall 一致；任何差异即不是等价改写。
- 权衡实验：预声明 Recall 目标与代价，独立冻结字段。
- worst-case 构造：界最松的数据（如高维近均匀分布）、判决全失效的输入；确认无性能退化即判决只赔不赚的上界。
- 报告命中率分布（分位数），不只报均值；命中率随分布漂移是适用范围的核心限制。

## 工作量口径

跳过的码是否计入扫描数、距离计算数，决定与基线的可比性；口径变化显式写入实验声明，不静默修改。
