# RaBitQ 参数与数据布局

## 参数含义

分开确认数据码字位宽与查询量化位宽。实现可能使用 nb_bits、ex_bits、qb 等名称；支持范围、零值含义及默认值从类型和参数校验取证。IVF 的 nlist/nprobe 和包装器候选倍率属于另一个配置层。

## 布局检查

逐项记录符号位、额外幅值位、旋转/中心化信息及范数、缩放、校正因子。实际 code_size 还可能包含对齐和因子，不能只用维度乘位宽估算整个向量存储。

## 查询缓冲

确认旋转后 query、量化位平面、norm 和校正因子由哪个对象持有，在哪个调用层生成、能否在列表间复用。位运算内核需核对位序、加权方式、popcount 和水平归约。

## 优化边界

增大位宽会改变码字、距离估计和成本；新增查询缓存会增加 setup 与内存足迹。维度特化须显式 guard，并测试非整字节、非向量倍数和无特化回退。距离估计中的校正项不能为减少计算而省略。
