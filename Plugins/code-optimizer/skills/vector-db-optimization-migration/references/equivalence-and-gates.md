## G0 feature-off 等价

- 关闭全部迁移宏/开关后，目标版本代码路径必须与目标上游逐位一致。
- 至少验证：相同查询、相同索引、相同参数下，top-k 标签与距离逐字节相同。
- 检查编译宏集合：`compile_commands.json` 中相关 TU 的 `-D` 与 `-march` 必须一致；仅看 `strings <目标引擎动态库>` 不够。
- 任何“关闭宏仍改变行为”的改动都说明迁移污染了原路径，立即停止。

## G1 UT/ST

- 运行目标版本完整 UT 与相关 ST；feature-on 与 feature-off 各一轮。
- 覆盖：正常、边界（尾部不足 batch、k>阈值、维度门控两侧）、并发、内存生命周期、fallback、序列化/save-load。
- UT 失败（含 `SIGSEGV`）优先怀疑 ABI/类布局，不是性能问题。
- benchmark recall 不变不能替代 UT/ST；两者分别给 verdict。
- 记录：用例数、通过/跳过/失败、环境条件、原始日志路径。

## G2 内核位级探针

目的：证明迁移后的 SIMD/PQ/距离/查表内核与目标上游（或源版本参照）在真实数据上是否逐位一致。

方法：

1. 用 `dlopen` 同时加载两个库（基线库与迁移库），避免符号冲突。
2. 用真实数据集切片生成输入，覆盖所有维度范围与 block 分发档（batch16/8/4/2/1）。
3. 对每个输入调用同一内核，比较输出位级，统计 mismatch 率与首个差异。
4. 覆盖 metric（L2/IP/NegaIP）、数据类型（f32/f16/u8/s8）、PQ 4/8-bit、尾部长度。

判读：

- 0 mismatch 才能进入 G3；任何 mismatch 都必须定位到具体循环/归约/分块。
- **归约顺序差异是常见根因**：按维度分块后每块单独归约再标量累加，与单累加器跑完全维度再单次归约，求和顺序不同，会产生 ULP 漂移。
- 若为了性能保留分块，必须证明 recall 门禁仍通过，或改为“单累加器跨块保持 + 单次归约”。

## G3 端到端 top-k dump

目的：证明整个搜索路径（图遍历/堆/visited/扫描/精排）输出与基线一致，而不只是单个内核。

方法：

1. 固定同一索引文件与同一批查询。
2. 分别用基线库与迁移库执行引擎的真实查询接口，dump 每条查询的 top-k 标签与距离。
3. 逐条逐字节比较；记录标签相同率、距离差、首个差异查询。
4. 对“索引构建路径”也要单独 dump：同一构建代码下比较 save/load 后索引，以及不同构建库对同一索引的搜索结果。

判读：

- 搜索库差异与索引差异必须分开：用“基线库 @ 迁移索引 / 迁移库 @ 迁移索引 / 基线库 @ 基线索引”三组交叉。
- 若“基线库 @ 迁移索引”与“迁移库 @ 迁移索引”标签相同，说明搜索路径无罪，漂移来自构建期索引（如 BFS 顶点重排改变 ID 顺序与 tie-break）。
- dump 工具必须用真实 `search(n=1)` 或等价路径，不得用简化重实现。

## G4 recall 零下降

- 每个数据集 recall@k 必须不低于目标版本冻结基线；任何下降（含 1e-6 级微差）⇒ 候选 REJECTED。
- 例外只有一种：给出位级一致的完整证明，且门禁数据集全部覆盖。
- 改变 FP 求和顺序、tie-break、量化精度、重排置换的改动，天然可能产生 1e-5~1e-4 级漂移；默认 `OPT_IN`，不得默认开启。
- 每数据集的基线/候选 recall 必须随 verdict 归档，保留原始日志。
- smoke 与正式采集两阶段都要执行门禁；不得只在小数据集通过就放大矩阵。

## G5 性能与同窗 ABBA

### 冻结与配对

- 目标基线独立冻结；源版本基线只用于解释机制来源，不用于计算迁移收益。
- 同机、同窗口、同核集/NUMA、同索引、同参数、同线程数；两臂紧密交错（ABBA/BABA）多轮。
- 记录每轮实际加载库的 SHA256、构建配置、机器负载；共享机器需报告背景负载。
- 不得跨核集、跨场次、跨 NUMA 直接比较；冻结基线的历史数字不能当同窗对照。

### 指标

- 每数据集 QPS、Recall、延迟；geomean；per-dataset floor。
- 噪声地板必须用**同配置自对照**实测标定：A 对 A（基线对基线）、B 对 B（候选对候选）各自紧贴交错重复 ≥10 次，取同配置内的波动幅度；采集条件（窗口、核集、预热、轮次）与 ABBA 效果测量完全一致。不得用“全 OFF 对全 ON”的差值当噪声地板——优化真实生效时，该差值同时包含波动与真实效果，会把收益或回归错误地折进噪声。若同配置对照也测出 ±3%~6% 信号，则同量级单变量结论不可信。
- 单轮单点、未复现的 ±2%~3% 不得作为接受依据。
- 报告所有有效轮次与剔除规则，不只保留最好一轮。

### 归因

- 把迁移收益与“目标版本更重底座”分开：先算目标基线→迁移版的增量，再与源版本内部增量比较，不能把跨版本绝对 QPS 相减当收益。
- 内核段与宿主段分开计时（如逐调用 `isb+cntvct` 括号），避免符号级 profiler 在负载下误归因。
- 若同一优化在不同数据集符号翻转，先查作用集（维度、metric、nprobe/efs、batch）与噪声地板，不急着下“通用有效/无效”。

## 证据级别与标记

| 级别 | 含义 | 用途 |
| --- | --- | --- |
| E0 | 假设 | 仅候选 |
| E1 | 源码静态证据 | 定位机制/差异 |
| E2 | 单次运行 | 冒烟/排查 |
| E3 | 可重复对照 | 接受单个机制的最低要求 |
| E4 | 冻结矩阵 + geomean + 异常说明 | 声称通用收益 |

输出统一标记 `[source]` / `[experiment]` / `[inference]` / `[unverified]`；verdict 与证据级别独立标注。

## 常见假阳性

- **LTO 位码**：`-flto` 下 `.o` 无重定位，静态反汇编找不到调用点，误判“未生效”；用运行时探针或链接后库。
- **A/B 臂配置错误**：config 的 `index_path` 指向基线索引或错误数据集，整轮结论作废；采集前打印并核对实际配置。
- **跨窗口比较**：基线在空闲窗口、候选在负载窗口，出现假收益/假回归；必须同窗紧贴交错。
- **SMT/PMU 污染**：物理核计数器包含姊妹线程流量，`cycles` 与 wall 时间矛盾；用 `isb+cntvct` 或干净核。
- **符号归因**：负载下 perf 样本符号占比可能把内核停顿归到宿主或相邻符号；用隔离回放与受控副本验证。
- **索引不同**：迁移后重建索引导致布局/ID 顺序变化，把索引差异误当搜索优化；固定共享索引或做三组交叉。
- **惰性宏大信号**：门控条件在测试参数下不生效却测出收益，说明噪声地板远高于预期，需先标定地板。
