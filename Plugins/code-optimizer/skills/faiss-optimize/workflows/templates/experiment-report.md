# 实验验收报告

## 结论

verdict、适用工作负载、质量结果、性能结论与主要限制。REWORK 列 return_to、reason 和 required_actions。

## 身份与变更

源码/补丁/基线、候选机制、开关、构建/库/数据/索引身份与冻结条件。

## 功能验证

实际路径、OFF/ON、guard/fallback、边界及相关并发/兼容性结果；原始记录和未覆盖项。

## 性能对照

预声明协议、完整时序、全部有效样本、统计口径、各工作负载收益、离散与漂移；诊断采样和正式测量分别标记。

## 验收依据

对应证据文件、可比性核验、收益归因及未解决问题，不给超出证据的结论。

## 交付

补丁与改动文件、复现命令、报告/原始产物位置、授权范围内的提交状态或待提交清单。
