# 像素布局、位深与合成

## 平面布局与色度采样

I420↔NV12 对 U/V zip/unzip，NV21 交换次序，Y 按行复制；各平面用自身 stride，4:2:0 尺寸为 ceil(W/2)×ceil(H/2)，奇数 ROI 起点重算色度相位。

## RGB 与 YUV 转换

RGB→I420 两行按 2×2 一次生成四 Y 和一组 UV，沿原平均/转换次序舍入。YUV→RGB 共享色度时在低分辨率域先算色度乘积，跨像素/行复用；插值色度按相位处理。固定颜色矩阵预存整数常数和偏置，RGB24 解交织后多算子复用。

2×2 一次平均先在宽类型中合并四个样本和舍入偏置，最后统一移位；周期偏置用全局坐标。ARM 映射见[成对累计求平均](../arm-simd-optimization/arm-neon-methods.md#成对累计求平均)。该路径与逐级舍入平均分开，奇数尺寸补边界样本。

## 位深与解包

满量程位复制：4→8 为 `(x<<4)|x`，5→8 为 `(x<<3)|(x>>2)`，6→8 为 `(x<<2)|(x>>4)`，8→b 为 `(x*257)>>(16-b)`，8≤b≤16。精确比例舍入采用对应映射；有限范围码值对齐扩展如 8→10 乘 4。

降位深用 `clip((x*s+bias)>>q)`；低位对齐 B 位截到 8 位移 B−8，高位对齐 W 位容器移 W−8。上游宽乘加直接接移位窄化，抖动在移位前加入。

按格式字节序用移位/掩码解包，直接接矩阵、混合、转换，最终交织输出；固定 alpha 广播，1 位 alpha 扩 b 位取 `0-a` 低 b 位。线性比例可折入系数，位复制保留位操作。

## Alpha 合成

预乘 over：`out=s+round(d*(255-a)/255)`，颜色与 alpha 共用 255−a。0≤x≤65025，令 t=x+128，则最近舍入除 255 精确为 `(t+(t>>8))>>8`；straight alpha 先按格式预乘。

### 预乘 Difference 与 Exclusion 消项

浮点预乘颜色 S、D，透明度 As、Ad：Difference 的输出颜色为 `S+D-2min(S*Ad,D*As)`，Exclusion 为 `S+D-2S*D`。把反预乘、混合、重新合成的实数公式展开后，alpha 除法及对应乘法相消；保留原输入精度和混合模式，不引入低精度近似。

RGBA 向量共用乘积与和：Difference 取两组交叉乘积的最小值，Exclusion 取逐通道乘积；先从 S+D 减一次，再把该乘积的 alpha lane 清零后减第二次。颜色完成双倍扣除，alpha 保持 `As+Ad-As*Ad`。已有同一预乘公式的 8 位内核也可共用这套 lane 组织，沿用原乘积归一化节点；不跨越既有整数反预乘的舍入节点消项。

## Bayer 去马赛克

Bayer 按 RGGB/GRBG/GBRG/BGGR 与全局 ROI 奇偶相位选四类核，循环以两行/两列推进；行缓存复用邻域，边缘导向用梯度选择方向及平局规则。RAW 解包、黑电平、白平衡与颜色转换按原阶段融合，保留各裁剪节点。

### 双线性邻域复用

R／B 位置保留中心同色样本，G 取上下左右四点均值，另一颜色取四个对角样本均值。G 位置保留中心 G，缺失的 R／B 分别沿其所在的水平／垂直方向取两点均值；方向随 Bayer 相位交换。

按相同相位跨两列生成一组输出，预计算上、下源行的纵向和，再移位得到左右两列纵向和，合成四对角和；中心行的左右和同时供 G 插值使用。共享宽和之后再分别加舍入偏置，四点均值不替换成两次已舍入的两点均值。三条源行循环装载，R/B 相位通过通道映射交换，同一算术核复用。

### 边缘导向绿色插值

在 R／B 点计算 `dh=abs(Gleft-Gright)` 与 `dv=abs(Gup-Gdown)`；选择差值较小方向的两点和，再进行均值舍入。水平与垂直的样本、和、差共享装载，方向选择用掩码；平局按指定方向或四点均值处理。此处是以两点梯度判向的插值形式，包含同色二阶修正的其他核另保留其修正项。已测 R／B 样本直通，另一颜色仍可使用四对角均值。
