# 预测、光流与时域手段

## 帧内与运动补偿

- DC：按可用顶行/左列及模式规定求均值，广播基础预测；启用 DC 边界滤波的模式再单独更新首行、首列与角点，内部块沿用广播结果。
- 方向预测：按模式预生成参考索引与分数权重；相邻输出共享参考装载，按行 SIMD 插值。
- 平面预测：行首计算基值，沿行递增固定项，保留规范的最终移位。
- 运动补偿：按整像素、水平分数、垂直分数、双向分数分派；双向分数使用水平行缓存再垂直滤波。
- 双参考预测：融合两路加权与偏置，最后在规定节点舍入裁剪。

帧内参考按已重建邻域和可用性规则填充；运动补偿系数按亮度/色度相位及位深选择。水平、垂直与 DC 的 SATD 评分可[共用源块变换](metrics.md#预测模式的变换域联合评分)。

## 块匹配运动搜索

同一参考帧、位移及像素处理方式下，先计算基础子块 SAD，再相加生成多种分块尺寸的失真；各分块的运动矢量率代价分别加入。SATD 仅在目标定义为这些子块 SATD 之和时复用，不能代替更大尺寸的 Hadamard 变换。

整数搜索先测预测矢量与邻域候选，用较小代价收紧后续阈值；菱形／六边形搜索复用上一轮已测位置，仅计算新边界候选。候选缓存和精确下界剪枝见[归约与搜索](metrics.md#归约与搜索)。分数像素细化按相位复用插值行与源块，插值后直接计算失真。

### 菱形与六边形候选推进

单位菱形在中心周围测试 `(±1,0)、(0,±1)`；最佳点成为新中心后，旧中心是已测邻点，复用其代价，仅补其余三个位置。相同目标函数下按坐标缓存已测候选，平值保持既定顺序；中心最优或搜索预算耗尽时停止。

六边形使用 `(±2,0)、(±1,±2)` 六个偏移。中心移动到最佳顶点后，旧中心和两个旧顶点覆盖新六边形的三个位置，仅计算移动方向前方的三个新顶点。以方向索引选三偏移，循环延长偏移表可省逐候选取模；停止后用中心周围八邻点细化。按候选三／四路批量计算 SAD，源块只加载一次。菱形与六边形属于局部搜索，搜索范围或迭代上限会改变候选覆盖。

### 分级淘汰与代价复用

SAD 候选先测整个块的和差下界，再拆成更细的不重叠组，使用 `Σg|Σsource_g-Σreference_g|` 下界；细分组后的下界不减。每一级下界加运动矢量率代价，超过当前 best 就淘汰，再对幸存者计算逐行 SAD 并提前终止。参考组和沿候选位置滚动更新；平局可能胜出的候选仅在严格大于阈值时剪枝。

使用 SAD 预筛再计算 SATD／RDO 时，SAD 排名不是后者的精确下界。可按速度档保留前 K 个候选或阈值范围内候选，随后以最终目标重新判优；K 与筛选阈值控制计算量和漏选程度。相同参考位置的像素失真可复用，依赖预测矢量的率代价单独重算。

## Lucas–Kanade

采用固定模板梯度的迭代形式时，每个金字塔层缓存梯度和 `G=Σ[Ix²,IxIy;IxIy,Iy²]`，并复用 G 的分解；各迭代只采样目标图、计算残差与右端项、解方程。窗口或权重改变时重算 G，不能用于每轮更新目标图梯度的形式。按特征点并行，低最小特征值的点直接标记失效；粗层位移放大后初始化细层。

## 时域融合与去隔行

同一对帧的运动场用于重采样多个通道；对齐值乘可靠性权重，累计后除权重和。遮挡或场景切换将对应参考权重置零，权重和为零时保留当前帧。

去隔行将已有场行直接复制，缺失行交给空间/时域滤波核；内部行批量处理，图像边缘单独处理。场奇偶与时间戳决定引用哪一场。

## IIR 与有限窗口

逐像素 IIR `s=a·input+(1-a)·s` 沿空间 SIMD；只依赖同位置旧状态时直接原地更新。等权 K 帧 FIR 用环形帧引用和 `sum+=new-old`，最后归一化；浮点递推与每次重算的舍入轨迹不同。窗口启动、reset 与尾部按原状态规则处理。

递归滤波每 lane 放独立像素、通道或实例，历史状态以 SoA 保存；串联节按同一节的独立实例并行，再推进下一节。

### 单路浮点二阶 IIR 时间展开

对 `y[n]=b0*x[n]+b1*x[n-1]+b2*x[n-2]+a1*y[n-1]+a2*y[n-2]`，保持原系数，将后续三个输出里的块内反馈逐层代入，预生成“四个输出×八个输入及历史状态”的系数矩阵。八个量是四个新输入、两个历史输入、两个历史输出；系数按列保存，每列恰好装入四个 lane。

运行时广播八个量，以八组向量乘加同时得到连续四个输出，再用末两个输出更新反馈。消除单个实例内部的逐样本等待，不依赖多通道凑并行；用更多预计算系数和部分额外乘法换取短依赖链。传递函数、初始历史量和浮点精度不变，验收观察连续处理后的误差而非只比较一个四样本块。
