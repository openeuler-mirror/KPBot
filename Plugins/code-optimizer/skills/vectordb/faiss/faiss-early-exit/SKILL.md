# Faiss 提前退出与剪枝

## 输入

候选/接受比例、当前判决成本（若已有）、可用的下界来源（量化误差界、堆顶阈值、块级聚合界）、召回要求、数据分布特征。

## 执行步骤

1. 判决类型选择：按 [判决契约](references/early-exit-contracts.md) 确定堆顶阈值、误差界或块级边界判决；每类判决有独立证明义务。
2. 证明义务：对每类判决给出"被剪掉的候选必不可能入选"的论证；无损路径的误差界必须对全部适用输入（查询与残差形态）有保证——推导得出或全覆盖包络；采样分位数包络只可用于独立的"速度/召回权衡"实验，不得作为无损剪枝的证明。
3. 分块组织：判决成本与块大小权衡；块级判决命中时整块跳过，未命中时块内仍逐码。
4. 门禁：纯实现优化要求结果集与 Recall 与基线精确一致；若判决影响结果集，声明为质量/速度权衡并另立实验。图遍历验证须包含"较远中转节点连接更近结果"的场景，确认跳过扩边不丢可达的更优候选。
5. worst-case：构造敌对分布（判决全部失效、界全部不紧）验证不劣化；报告判决命中率分布。
6. 开关与回退：判决默认关闭或取保守阈值；记录命中率与节省，命中率过低的负载自动不值得。

## 输出

判决类型与证明、块组织、门禁结果、worst-case 数据、开关/回退与适用范围。

## 约束

- 判决方向按 metric 定：L2 用不高于真实距离的下界，下界不低于堆顶最差值才可剪枝；最大内积用不低于真实得分的上界，上界不高于堆顶最差值才可剪枝；相等时遵循原结果处理器的并列规则。保守方向（L2 下界偏小、内积上界偏大）只减少剪枝、不会漏选；朝反方向收紧（L2 下界偏大或内积上界偏小）即漏选。
- 堆未满阶段不得按堆顶剪枝（阈值未形成）。
- 判决收益依赖数据分布；结论附命中率分布与适用负载描述。
- 计数语义：被跳过的码不计入扫描数时，工作量口径变化要显式声明。
